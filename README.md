# 职业军师 · Career Compass

> 把职业发展理论、市场洞察和可执行策略，装进一个真正站在用户一边的 AI 职业规划军师。

## 项目简介

**career-compass** 是一个面向 1-10 年职场人的职业规划 Skill。基于 Holland、Super、Schein、Bandura 等经典职业发展理论，结合中国就业市场实际，提供从自我探索、职业决策到行动落地的全流程支持。

## 功能特点

- **五步法分析框架**：情绪落地 → 现状拆分 → 利益判断 → 明确建议 → 行动收束
- **21 篇学术知识库**：覆盖职业发展理论、决策模型、职业倦怠、行业趋势等
- **24 篇实战指南**：简历、面试、薪酬、转行、副业、创业等全场景
- **安全边界**：不诊断心理疾病、不鼓励裸辞、不协助造假
- **长期记忆**：支持跨任务职业档案（需用户同意后启用）

## 适用场景

- 职业迷茫，不知道自己适合什么
- 想跳槽但不确定时机和方向
- 想转行但不知道转什么、怎么转
- 职业倦怠，想自救或判断要不要走
- 拿到 offer 不知道怎么谈薪资
- 想做副业/自由职业/创业，但不确定可行性
- 应届生找工作，不知道怎么选
- 职场新人，想快速适应和成长

## 理论基础

基于以下经过学术验证的职业发展理论：

- **Holland RIASEC** 职业兴趣模型
- **Super** 生涯发展阶段理论
- **Schein** 职业锚理论
- **Bandura** 自我效能感与社会认知理论
- **JD-R** 工作要求-资源模型（职业倦怠）
- **CIP** 认知信息加工理论（职业决策）
- **Self-Determination Theory** 自我决定理论（工作动机）

## 安装使用

### 方式一：WorkBuddy 本地 Skill

将项目放入 WorkBuddy workspace 的 `.trae/skills/` 目录下：

```bash
# Windows (目录链接方式，文件本体可在任意位置)
mklink /J "C:\path\to\workspace\.trae\skills\career-compass" "D:\projects\career-compass"
```

然后在 WorkBuddy 中直接描述你的职业困惑即可自动触发。

### 方式二：GitHub 安装

从 GitHub 仓库安装（需先发布到 GitHub）：

```
/github <username>/<repo>
```

## 安全声明

- 本 Skill 不提供心理疾病诊断，如有需要请寻求专业帮助
- 职业建议仅供参考，最终决策请结合自身情况
- 不鼓励无计划裸辞、不协助简历造假、不违反劳动法
