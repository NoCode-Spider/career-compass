面向职业迷茫、跳槽犹豫、转行纠结、倦怠内耗的 AI 职业军师，结合经典职业发展理论、中国就业市场实际和可落地的行动方案，把复杂的职业选择变成清晰的下一步。

如果它能让你少一次内耗、多一次清醒，欢迎点亮一个 ⭐ Star：方便以后回来，也帮助更多有同样困惑的人发现它。

很多职业建议只有两个答案："坚持"或"辞职"。职业军师不会只凭一句话替你下结论：它先接住情绪，再把事实、选项和风险拆开；既看兴趣，也看现实条件、机会成本和长期选择权，最后给出可以真正执行的下一步。

它不只是一个话术库。它能帮你做技能盘点、行业调研、薪资谈判策略、转行路径设计；也能把分析落到一份可投递的简历、一次可演练的面试、一张可执行的学习计划表。它是一套覆盖职业全周期、面向多元发展路径、能够解释建议理由的 **Codex Skill**，兼容 TRAE、WorkBuddy 及所有支持 Codex 标准的 AI 助手。

## 不预设你应该走哪条路

职业军师支持体制内、互联网、传统行业、自由职业、创业、gap year 等不同发展路径，也尊重每个人的节奏和选择。它同样可以讨论转行、跳槽、副业、降薪、躺平等各种职业状态。

系统不假设"正确"的职业道路：不是每个人都要往上爬，不是每个人都要进大厂，也不是每个人都要年薪百万。判断依据始终是具体的人、具体的需求、具体的现实条件和具体的选择权。

> ⚠️ **边界声明**：本 Skill 提供职业发展方向的分析与建议，**不构成专业的心理咨询或医疗诊断**。如出现严重抑郁、焦虑、自我伤害倾向等症状，请及时寻求专业帮助。

## 工作原理

### 五步分析框架

职业军师遵循一套结构化的分析流程，确保每次回答都有章法、可追溯：

```
情绪落地 → 现状拆分 → 利益判断 → 明确建议 → 行动收束
```

1. **情绪落地**：先接住情绪，让用户感到被理解，再进入分析
2. **现状拆分**：把模糊的"迷茫/不爽"拆成具体的、可讨论的维度
3. **利益判断**：分析不同选择的利弊、成本、风险和机会
4. **明确建议**：给出稳健 / 策略 / 强势三版方案，说明适用条件
5. **行动收束**：落到具体的小事，给观察窗口和停止条件

### 安全边界

- **不评判**：不道德评判、不贴标签、不灌输"应该"
- **不越界**：不冒充心理咨询、不做医疗建议、不替用户做决定
- **不硬给**：信息不足时直说，不编答案
- **不鼓励危险行为**：不鼓励裸辞、不协助造假、不违反劳动法

| 平台 | 出品方 | 状态 | 安装方式 |

| **其他 Codex 标准平台** | — | ✅ 兼容 | 放入 skills 目录即可 |

> Codex Skill 是一个开放的技能标准，不同的 AI 助手只要支持这个标准，都可以安装使用同一份 Skill。

## 安装使用

### 方式一：通过 TRAE 安装（推荐）

在 TRAE 中输入：

```
/github NoCode-Spider/career-compass
```

安装完成后，直接描述你的职业困惑即可自动触发。

### 方式二：通过 WorkBuddy 安装

在 WorkBuddy 中：
1. 打开设置 → 技能管理
2. 选择"从 Git 仓库导入"
3. 粘贴仓库地址：`https://github.com/NoCode-Spider/career-compass.git`

### 方式三：本地安装

将项目放入 AI 助手 workspace 的 skills 目录下：

```bash
# TRAE - Windows (目录链接方式，文件本体可在任意位置)
mklink /J "C:\path\to\workspace\.trae\skills\career-compass" "D:\projects\career-compass"

# WorkBuddy / 其他 Codex 平台
# 将整个项目目录放入对应的 skills 文件夹即可
```
