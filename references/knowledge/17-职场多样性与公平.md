# 17-职场多样性与公平

> 本篇涵盖职场多样性、公平性和隐性偏见。当用户涉及"因为性别/年龄/学历被歧视""晋升不公平""感觉被区别对待"时，本文件提供理解框架和应对策略。

## 证据等级说明

| 等级 | 说明 |
|------|------|
| 较强证据 | 性别薪酬差距统计、隐性偏见测试 |
| 理论框架 | 多样性管理理论 |

---

## 一、性别薪酬差距

### 1.1 全球数据

世界经济论坛 2024 年报告：全球性别薪酬差距按当前速度需要 **134 年** 才能消除。

**中国情况：**
- 女性平均薪酬约为男性的 80-85%（因行业和城市不同有差异）
- 差距随职级升高而扩大——初级岗位差距小，高管层差距大
- 生育是导致女性职业中断和薪酬下降的主要因素之一

### 1.2 差距来源

| 来源 | 说明 |
|------|------|
| 职业隔离 | 女性集中在低薪行业（教育/护理），男性集中在高薪行业（科技/金融） |
| 生育惩罚 | 女性生育后薪酬下降，男性生育后薪酬不变甚至上升（"父亲奖金"） |
| 谈判差异 | 女性谈薪的频率和幅度低于男性 |
| 隐性偏见 | 评估"领导力"时对男性和女性使用不同标准 |

---

## 二、隐性偏见

### 2.1 概念

隐性偏见（Implicit Bias）是无意识的、自动的刻板印象——即使个人在意识层面不持有歧视态度，潜意识仍可能影响判断和决策。

Greenwald, A. G., & Banaji, M. R. (1995). Implicit social cognition. *Psychological Review*, 102(1), 4–27.

### 2.2 常见职场隐性偏见

| 偏见 | 表现 |
|------|------|
| 性别偏见 | "她太柔了不适合管理岗""他太年轻不像领导" |
| 年龄偏见 | "35 岁了还做基础岗""应届生不靠谱" |
| 学历偏见 | "非 985 不要""本科以下不看" |
| 外貌偏见 | "形象好更适合前台""长得高更有领导气质" |
| 母语偏见 | "口音重不够专业" |

### 2.3 对用户的含义

- 遭遇偏见不是用户的问题，但理解偏见的运作方式有助于应对
- 纠正隐性偏见的责任在组织而非个人——个人可以选择应对或离开
- "是不是我的问题"是遭遇偏见后最常见的自我怀疑——帮用户区分系统性偏见和个人不足

## 三、年龄焦虑

### 3.1 "35 岁现象"

中国职场的"35 岁现象"是真实存在的结构性问题——部分行业/公司在招聘中设置 35 岁上限。这在互联网行业尤为突出。

### 3.2 应对策略

| 策略 | 说明 |
|------|------|
| 向上走 | 管理岗/高级专业岗通常不受年龄限制 |
| 向深走 | 成为不可替代的专家，稀缺性超越年龄 |
| 向宽走 | 跨领域能力组合比单一技能更抗年龄 |
| 向下兼容 | 到年龄友好行业（医疗/教育/国企/体制内） |
| 自己走 | 创业/自由职业/独立顾问 |

---

## 四、对用户问题的典型应用

### "因为我是女性所以晋升轮不到我"

→ (1) 不否认可能性——系统性偏见确实存在。(2) 帮用户区分：是偏见还是能力/投入的差距？如果是偏见，考虑：当前组织是否值得继续？有没有更公平的环境？(3) 积累不可替代的稀缺性——偏见在高替代性岗位最严重，在稀缺性岗位被克制。

### "35 岁了很焦虑"

→ (1) 35 岁现象在某些行业真实存在，不是焦虑过度。(2) 用四种策略评估：向上走、向深走、向宽走、向下兼容。(3) 如果当前行业对年龄极不友好，考虑提前转型到年龄友好行业。

### "因为学历非 985 找不到好工作"

→ (1) 学历偏见在应届生招聘中确实严重，但社招权重递减。(2) 用技能证据（项目、作品、认证）补偿学历叙事。(3) 65% 的招聘经理愿意仅凭技能录用（Resume Genius 2024）——找到这些公司。
