# 18-心理健康与职场适应

> 本篇涵盖职场心理健康、适应障碍和何时该寻求专业帮助。当用户表现出持续情绪低落、全面兴趣丧失、严重睡眠障碍或自我伤害念头时，本文件提供识别和转介框架。**重要声明：本 skill 不是心理健康诊断工具，涉及可能的心理疾病必须建议用户寻求专业精神卫生服务。**

## 安全边界

**以下信号必须建议专业评估：**
- 持续两周以上全面兴趣丧失（不只对工作，对一切事物）
- 持续睡眠障碍（严重失眠或嗜睡）
- 明显体重变化（不是刻意控制）
- 自我伤害或自杀念头
- 无法正常完成日常功能（不能起床、不能出门）
- 物质滥用（酒精/药物依赖）

**本 skill 不诊断以下状况，但需要识别并转介：**
- 抑郁症
- 焦虑障碍
- 适应障碍
- 职业倦怠发展为临床问题
- 人格障碍

---

## 一、倦怠 vs 适应障碍 vs 抑郁

### 1.1 三者区分

| 维度 | 职业倦怠 | 适应障碍 | 抑郁症 |
|------|---------|---------|--------|
| 触发源 | 持续工作压力 | 特定生活变化（换工作/搬家/分手） | 可能无明确触发 |
| 范围 | 限工作领域 | 部分生活领域受影响 | 全面影响所有领域 |
| 核心症状 | 情感耗竭+去人格化+成就感降低 | 情绪低落/焦虑+功能下降 | 持续低落+兴趣丧失+认知症状 |
| 持续时间 | 随工作环境改善缓解 | 通常 3-6 个月自限 | 至少 2 周，不治疗可能持续 |
| 自知力 | 通常知道"工作让我累了" | 知道"最近不好" | 可能丧失自知力 |
| 治疗 | 改善环境+调整 | 时间+支持+必要时心理咨询 | 可能需要药物+心理治疗 |

### 1.2 识别要点

用户可能描述：
- "工作让我精疲力竭" → 倦怠为主
- "换了新工作后一直不开心" → 适应障碍可能
- "什么都不想做，活着没意思" → **可能抑郁，必须转介**

## 二、职场适应障碍

### 2.1 概述

适应障碍（Adjustment Disorder）是对特定压力源（如入职新工作、晋升、转行、被裁员）出现的**超出正常反应强度的情绪/行为反应**，在压力源出现后 3 个月内发生，通常在压力源消除后 6 个月内缓解。

American Psychiatric Association (2013). *DSM-5*. Washington, DC.

### 2.2 职场适应障碍的表现

- 入职新工作后持续 1 个月以上明显的焦虑/低落
- 工作变动后工作表现明显下降（不是能力问题而是心理反应）
- 对新环境的适应明显慢于正常水平
- 持续的"我不属于这里"感

### 2.3 与正常过渡期的区分

Bridges 过渡模型的"中性区"（参见知识库 08）会带来一定程度的迷茫和不适——这是正常的。但如果不适感**持续超过 3 个月且没有缓解趋势**，或**严重影响了日常功能**（不能完成工作、严重睡眠问题），需要考虑适应障碍可能。

## 三、焦虑与职业决策

### 3.1 职业决策焦虑

CIP 理论（参见知识库 02）指出：焦虑状态与负性职业思维显著关联，焦虑削弱信息处理能力。这意味着：

- 在高度焦虑下做职业决策 → 决策质量更低
- 负性思维（"我选什么都会后悔"）→ 进一步加剧焦虑
- 恶性循环：焦虑→决策困难→更焦虑

### 3.2 干预策略

| 策略 | 适用 | 做什么 |
|------|------|--------|
| 情绪降级 | 焦虑高到无法思考 | 先做放松/运动/社交，不做决策 |
| 限定窗口 | 拖延式焦虑 | 给决策设定截止日期，截止前收集信息，截止时必须选 |
| 外部视角 | 过度反刍 | 问"如果朋友面临这个选择，我会建议什么" |
| 信息减少 | 信息过载焦虑 | 限制信息收集量，3 个选项足够 |
| 小步行动 | 行动瘫痪 | 做一个极小的不相关行动，打破"什么都没做"的惯性 |

## 四、何时建议专业帮助

### 4.1 转介信号清单

**必须建议专业评估的信号（任一出现）：**

- [ ] 持续 2 周以上每天大部分时间情绪低落
- [ ] 对以前喜欢的活动完全失去兴趣
- [ ] 严重睡眠障碍（入睡困难/早醒/嗜睡）持续 2 周以上
- [ ] 明显食欲/体重变化（非刻意控制）
- [ ] 持续的疲倦或精力丧失
- [ ] 自我评价过低，或过度的自责/自罪感
- [ ] 思维或集中注意能力下降
- [ ] 反复出现死亡/自杀念头

### 4.2 转介话术建议

**温和版：**
> "你描述的感受听起来很沉重。我注意到有些表现可能不只是工作压力——持续这么久的低落和睡眠问题可能需要专业的支持来帮你评估。你考虑过找心理咨询师或精神科医生聊聊吗？这不是说你有问题，是给自己一个被准确评估的机会。"

**直接版：**
> "你提到的一些感受——什么都不想做、活着没意思、睡不好——这些可能不是单纯的工作问题，可能是抑郁的信号。我建议你尽快做一个专业的心理评估，可以先用 [心理健康热线/在线平台] 预约。"

### 4.3 中国心理服务资源

| 类型 | 渠道 |
|------|------|
| 心理热线 | 各城市心理援助热线（如北京 010-82951150） |
| 在线平台 | 简单心理、壹心理、好心情等 |
| 线下 | 精神卫生中心、三甲医院心理科 |
| EAP | 部分公司有员工心理援助计划 |

## 五、对用户问题的典型应用

### "什么都不想做，觉得什么都没意义"

→ 如果限工作领域 → 倦怠可能（参见知识库 05）。如果全面影响所有领域（以前喜欢的事也不想做）→ **可能抑郁，必须建议专业评估**。用转介信号清单逐项检查。

### "换了新工作后一直焦虑/不开心"

→ 如果在 3 个月内 → 可能正常过渡期或适应障碍。用 Bridges 模型理解。如果严重影响功能（不能工作/严重失眠）→ 建议专业评估。

### "做职业决策时特别焦虑"

→ CIP 理论解释：焦虑削弱信息处理。策略：先情绪降级再决策；限定决策窗口；减少信息量；用小步行动打破瘫痪。如果焦虑持续影响日常生活 → 建议心理咨询。

### "我觉得活着没意思"

→ **立即评估自杀风险。** 直接询问："你有想过伤害自己吗？" 如果有 → 提供危机热线并建议立即就医。本 skill 不处理此级别问题。
