# 12-中国就业市场与劳动法

> 本篇涵盖中国就业市场的法律框架和实操要点。当用户涉及离职、竞业协议、社保公积金、试用期、劳动纠纷时，本文件提供基础法律知识框架。**重要声明：本 skill 不是法律咨询工具，涉及具体法律问题必须建议用户咨询专业劳动法律师。**

## 安全边界

**本文件仅提供基础知识框架，不构成法律建议。** 以下情况必须建议用户咨询专业律师：
- 面临劳动仲裁或诉讼
- 竞业协议纠纷
- 工伤认定
- 公司大规模裁员/非法解除
- 涉及竞业限制补偿金争议

## 一、劳动合同法核心要点

### 1.1 劳动合同类型

| 类型 | 适用场景 | 核心规定 |
|------|---------|---------|
| 固定期限合同 | 最常见 | 约定终止日期；连续订立两次固定期限合同后，第三次应签无固定期限 |
| 无固定期限合同 | 连续工作满 10 年等 | 无约定终止日期；不是"铁饭碗"但解除更难 |
| 以完成一定工作任务为期限 | 项目制 | 任务完成即终止 |

### 1.2 试用期规定

| 合同期限 | 试用期上限 | 试用期工资下限 |
|---------|-----------|--------------|
| 3 个月以下 | 不得约定试用期 | — |
| 3 个月~1 年 | 不得超过 1 个月 | 不低于转正工资 80% |
| 1~3 年 | 不得超过 2 个月 | 不低于转正工资 80% |
| 3 年以上或无固定 | 不得超过 6 个月 | 不低于转正工资 80% |

**关键：** 同一用人单位与同一劳动者只能约定一次试用期。

### 1.3 离职与解除

| 离职方式 | 条件 | 经济补偿 |
|---------|------|---------|
| 协商解除 | 双方同意 | 看协商结果 |
| 劳动者提前 30 天通知 | 正式员工，无需理由 | 无 |
| 劳动者试用期通知 | 提前 3 天 | 无 |
| 用人单位过错（如拖欠工资） | 劳动合同法 38 条 | 需支付经济补偿 |
| 用人单位单方解除（非过错） | 如不胜任、客观情况变化 | 需支付经济补偿（N 或 N+1） |
| 违法解除 | 用人单位无合法理由 | 需支付赔偿金（2N） |

**经济补偿计算：** 每满 1 年支付 1 个月工资（N）。月工资指离职前 12 个月平均工资。高收入者有上限（当地社平工资 3 倍）。

## 二、社保与公积金

### 2.1 五险一金

| 项目 | 个人缴纳比例（约） | 单位缴纳比例（约） | 用途 |
|------|------------------|------------------|------|
| 养老保险 | 8% | 16% | 退休后养老金 |
| 医疗保险 | 2% | 8-10% | 医疗报销 |
| 失业保险 | 0.5% | 0.5% | 失业后领取 |
| 工伤保险 | 0% | 0.2-1.9% | 工伤赔偿 |
| 生育保险 | 0% | 0.5-1% | 生育津贴 |
| 住房公积金 | 5-12% | 5-12% | 购房/租房 |

**注意：** 比例因城市不同有差异，以上为大致范围。

### 2.2 裸辞的社保风险

- 裸辞后社保断缴可能影响：购房资格（多地要求连续缴纳）、积分落户、医保报销
- 断缴 3 个月内补缴可视为连续（部分城市）
- 可通过灵活就业身份自行缴纳养老和医疗

## 三、竞业限制协议

### 3.1 核心规定

| 要点 | 规定 |
|------|------|
| 适用对象 | 高级管理人员、高级技术人员、其他负有保密义务的人员 |
| 期限 | 不得超过 2 年 |
| 经济补偿 | 用人单位需在解除/终止合同后按月支付 |
| 补偿标准 | 不低于离职前 12 个月平均工资的 30%（部分地区有差异） |
| 违约金 | 劳动者违反需支付违约金 |

### 3.2 常见陷阱

1. **竞业范围过宽**：有些公司要求所有同行不能去，实际应限于有竞争关系的业务范围
2. **补偿不支付**：如果公司不按月支付补偿，劳动者可请求解除竞业限制
3. **签字时的注意**：入职时签的竞业协议在离职时不一定生效——取决于公司是否实际启动并支付补偿

## 四、中国就业市场结构

### 4.1 用人主体类型

| 类型 | 特点 | 职业稳定性 |
|------|------|-----------|
| 国企/事业单位 | 户口/编制/福利好但薪资有天花板 | 高 |
| 公务员 | 最稳定但考试竞争激烈 | 最高 |
| 民营企业 | 灵活、成长快但稳定性参差 | 中低 |
| 外企 | 管理规范但近年退出/缩减 | 中 |
| 平台经济/灵活就业 | 自由但缺乏社保保障 | 低 |

### 4.2 应届生 vs 往届生

- 应届生身份在国企/公务员/事业单位招聘中有优势
- 很多央企/国企只招应届或毕业 2 年内
- 跳槽 2-3 次后失去应届身份，进入社招渠道

## 五、对用户问题的典型应用

### "公司要我签竞业协议，该签吗？"

→ 本 skill 不给法律建议。提示用户关注：(1) 竞业范围是否合理（不是"全行业不能去"）；(2) 补偿标准是否明确；(3) 咨询劳动法律师审查条款。

### "裸辞后社保怎么办？"

→ 提示：(1) 断缴影响购房/落户/医保；(2) 可通过灵活就业身份自缴养老+医疗；(3) 3 个月内补缴可视为连续（因城市而异）。

### "公司要裁员/辞退我，我能拿多少？"

→ 本 skill 不给法律建议。提示：N（工作年限×月工资）是经济补偿的基础线。如果是违法解除，可主张 2N。具体咨询律师。

### "试用期被辞退怎么办？"

→ 试用期解除也需要理由（不符合录用条件），不能随意辞退。如公司无证据证明"不符合录用条件"，可能构成违法解除。
