# 13-薪酬结构与市场定价

> 本篇涵盖薪酬构成、市场定价逻辑和谈判策略。当用户涉及"我这个岗位值多少钱""怎么谈薪资""offer 怎么评估"时，本文件提供薪酬知识和评估工具。

## 一、薪酬构成

### 1.1 典型薪酬包结构

| 组成 | 说明 | 占比参考 |
|------|------|---------|
| 基本月薪 | 固定部分，税前 | 50-70% |
| 绩效奖金 | 浮动部分，与个人/公司绩效挂钩 | 10-30% |
| 年终奖 | 年度奖励，1-4 个月常见 | 10-30% |
| 股票/期权 | 上市公司 RSU，创业公司期权 | 0-40%（因公司而异） |
| 补贴 | 餐补/交通/住房/通讯 | 5-10% |
| 公积金补充 | 部分公司额外缴纳 | 5-10% |

### 1.2 薪资相关概念

| 概念 | 定义 | 注意 |
|------|------|------|
| 税前/税后 | 税前工资 vs 实际到手 | 中国个税有专项扣除 |
| 14 薪/16 薪 | 年发 14 或 16 个月 | 多出的部分可能年终发 |
| Base | 月薪基数 | 不含奖金和股票 |
| 总包 TC | Total Compensation 所有现金+股权价值 | 股权需折算且有时间限制 |
| 薪资带宽 | 岗位薪资范围（如 P6: 20-30k） | 大厂有明确等级体系 |

## 二、市场定价逻辑

### 2.1 薪酬决定因素

| 因素 | 影响程度 | 说明 |
|------|---------|------|
| 行业 | 极高 | 互联网/金融 > 制造/教育 |
| 城市 | 高 | 北上深 > 新一线 > 二线 |
| 公司规模/类型 | 高 | 头部大厂 > 中小企业 |
| 职级 | 高 | 等级越高差距越大 |
| 学历 | 中 | 校招影响大，社招递减 |
| 经验年限 | 中 | 3-5 年是关键分水岭 |
| 技能稀缺性 | 高 | AI/算法 > 通用开发 > 基础运维 |

## 三、薪酬谈判策略

### 3.1 谈判时机

| 时机 | 策略 | 风险 |
|------|------|------|
| 收到 offer 后 | 最佳时机——对方已表达意愿 | 低 |
| 面试中谈期望 | 给范围不给精确数 | 中 |
| 入职后要求加薪 | 需业绩支撑 | 高 |

### 3.2 总包评估框架

评估 offer 时不只看月薪，要看总包：

```
月收入 = 基本工资 + 月补贴
年收入 = 月收入 × 12 + 年终奖 + 其他奖金
总包 = 年收入 + 股票年度价值 + 公积金补充
到手 = 总包 - 个税 - 五险一金个人部分
```

### 3.3 谈判要点

1. **先让对方出价**：让对方先说预算，再根据对方报价调整
2. **给范围不给精确数**："我的期望是 X-Y"，X 是底线，Y 是理想
3. **用市场数据支撑**：引用行业薪酬报告，不是"我觉得我值更多"
4. **谈总包不谈月薪**：月薪低但年终奖高/股票多的 offer 可能总包更高
5. **不要只谈钱**：成长机会、工作弹性、团队质量也是"薪酬"的一部分

## 四、对用户问题的典型应用

### "我这个岗位值多少钱？"

→ 使用招聘平台（BOSS 直聘/脉脉/拉勾）搜索同城市同岗位同经验年限的薪资范围，取中位数作为参考。注意区分"发布的薪资范围"和"实际成交薪资"。

### "怎么谈薪资？"

→ (1) 先拿到 offer 再谈；(2) 给范围不报精确数；(3) 用市场数据说话；(4) 评估总包不只看月薪。

### "offer 怎么评估？"

→ 用总包评估框架：(1) 月薪×12 + 年终奖 + 股票价值 + 补贴 + 公积金；(2) 对比当前总包的增长率（15%+ 是合理跳槽涨幅）；(3) 评估非货币因素（成长、稳定、通勤）。
