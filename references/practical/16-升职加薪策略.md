# 16-升职加薪策略

> 适用场景：想升职或加薪，但不知道怎么争取。
> 目标读者：在职且有一定业绩积累的人。

---

## 一、升职加薪的本质

升职加薪不是"你做得好就应该给你"，而是**你创造的价值超过了当前岗位的价格**，公司需要用更高的薪酬/更高的职位留住你。

---

## 二、升职策略

### 2.1 升职的前提

升职不是靠熬年限，是靠你已经在做下一级的工作了。

| 前提 | 说明 |
|------|------|
| **当前工作做好了** | 本职工作都做不好，谈什么升职 |
| **已经承担了更高的职责** | 你已经在做下一级的工作了，只是没有头衔 |
| **有不可替代性** | 你走了公司会很痛/很难找人替代 |
| **时机合适** | 公司在发展，有晋升的空间和预算 |
| **领导认可你** | 你的直属领导愿意帮你争取 |

### 2.2 怎么判断自己有没有资格

问自己这几个问题：

1. 如果我现在离职，公司找一个人替代我，需要给那个人开多少钱？
   - 如果需要开更高的价 — 你可以谈加薪
   - 如果找一个更便宜的也能做 — 你没什么议价权

2. 我现在的工作内容，是不是已经超出了当前职级的要求？
   - 是 — 你已经在做下一级的工作了，可以谈升职
   - 不是 — 先把当前工作做到超出预期

3. 我有没有最近 3-6 个月的突出成果？
   - 有 — 这是你谈判的筹码
   - 没有 — 先做出成果再说

### 2.3 升职前准备

**做高一级的工作，等一个合适的头衔。**

- 主动承担更多责任
- 帮领导分担压力（做领导的延伸）
- 带新人/带小项目（展示管理能力）
- 跨部门建立影响力（不只是在组内有名）
- 定期和领导聊你的发展（让他知道你想成长）

### 2.4 怎么和领导谈升职

**话术 1（发展导向型）：**
> "老板，我想和您聊聊我的职业发展。我来公司 X 年了，这期间做了[成果 A/B/C]。我想在职责上有更多成长，比如[你想承担的方向]。您觉得我目前的水平怎么样？接下来需要在哪些方面提升，才能达到[下一级]的要求？"

**话术 2（成果导向型）：**
> "老板，想和您同步一下我最近的工作进展。过去半年我主要做了[成果 1/2/3]，尤其是[最突出的一个]。接下来我想承担更多，比如[具体方向]。您看这边有没有合适的机会？"

**要点：**
- 用成果说话，不是"我来了很久"
- 不说"我要升职"，说"我想承担更多成长"
- 把球抛给领导——"您觉得我还需要提升什么"
- 不要逼领导当场给答案，给时间让他考虑和争取

## 三、加薪策略

### 3.1 什么时候谈

| 好时机 | 不好的时机 |
|--------|-----------|
| 刚完成一个大项目后 | 公司业绩不好/裁员时 |
| 绩效评估前 1-2 个月 | 你刚犯了一个错误 |
| 领导心情好的时候 | 领导特别忙的时候 |
| 有外部 offer 时（慎用） | 仅仅因为"别人都涨了" |
| 你承担了更多职责之后 | 你什么都没改变，单纯想涨 |

### 3.2 加薪谈判话术

**话术 1（业绩导向）：**
> "老板，我想和您聊聊薪资的事。过去这一年，我主要负责了[项目 A]和[项目 B]，分别取得了[量化成果 A]和[量化成果 B]的成绩。现在我的职责也比入职时增加了不少，比如[新增职责]。基于这些，我希望薪资能有 20% 左右的调整。您觉得怎么样？"

**话术 2（市场行情导向）：**
> "老板，我想和您沟通一下薪资。我了解了一下市场行情，同岗位同经验的水平大概在[范围]。我目前的薪资是 XX，和市场水平有一定差距。我对公司和团队都很认可，也想长期发展，所以想和您聊聊有没有调整空间。"

**话术 3（有 offer 兜底）：**
> "老板，有件事想和您说一下。最近有个机会找过来，薪资比现在高不少。但我对团队和目前做的事都很有感情，不想走。所以想先和您聊聊，看这边有没有调整的空间？"

**注意：** 有 offer 谈薪是双刃剑——
- 好处：有筹码
- 风险：领导可能觉得你"心已经不在了"，反而不给你机会
- 只有当你真的愿意走的时候才用这招

### 3.3 谈不成怎么办

| 情况 | 怎么办 |
|------|--------|
| "公司有固定的调薪周期" | 问清楚下一次调薪时间和条件，设定明确目标 |
| "今年预算不够" | 探讨非现金补偿（更多假期、学习预算、职级提升） |
| "你的表现还不够" | 问清楚具体差距在哪里，制定改进计划 |
| 完全没空间 | 评估一下：是暂时的还是长期的？长期没空间就考虑外面机会 |

## 四、晋升通道

### 4.1 两条路：管理 vs 专业

大多数公司有两条晋升路径：

| 路径 | 特点 | 适合谁 |
|------|------|--------|
| **管理路线** | 带团队、管人、定方向 | 喜欢带人、擅长沟通、有战略思维 |
| **专业路线** | 深耕技术/专业，做专家 | 喜欢钻研、不想管人、在专业上有追求 |

### 4.2 怎么选

问自己：

1. 你做什么事的时候最有成就感？
   - 带领团队完成一个项目 → 管理
   - 自己解决一个技术难题 → 专业

2. 你对什么更没耐心？
   - 团队效率低、人不行 → 可能不适合管理（管理就是和人打交道）
   - 技术不够深入、做的事没技术含量 → 可能不适合专业路线

3. 5 年后你想成为什么样的人？
   - 管一个团队/一个业务 → 管理
   - 成为某个领域的专家 → 专业

**提醒：** 不是选了就不能变。很多人先做专业再转管理，也有人做了管理发现不喜欢转回专业。

## 五、常见误区

| 误区 | 正确认知 |
|------|---------|
| "做得好就该升职" | 做得好是基本要求，升职需要你已经在做下一级的工作 |
| "领导知道我想要什么" | 领导很忙，你不说他可能真不知道。主动沟通 |
| "加薪靠谈，谈一次涨一次" | 加薪的核心是你创造的价值，不是谈判技巧 |
| "不谈就是吃亏" | 确实，会哭的孩子有奶吃。但哭也要有水平 |
| "跳槽涨得快" | 短期是的，但频繁跳槽有长期代价。内部晋升+外部机会结合 |
| "没升职就是我不行" | 可能是公司没空间，不一定是你不行 |

## 六、升职加薪准备清单

想谈之前，先确认：

- [ ] 我最近 6 个月有突出的、可量化的成果
- [ ] 我承担了超出当前职级的职责
- [ ] 我了解市场行情（同岗位的薪资范围）
- [ ] 我知道下一级的要求是什么，且我已经达到了 70% 以上
- [ ] 我和领导的关系还不错（不是最差的那种）
- [ ] 我选对了时机（不是公司困难期、不是刚犯错）
- [ ] 我有明确的目标（涨多少/升到什么位置）
- [ ] 我也考虑了替代方案（涨不了薪怎么办）
- [ ] 我做好了"谈不成也不影响关系"的心理准备
- [ ] 我不是因为"别人涨了我没涨"才谈的，而是因为我确实值更多

---

> **停止条件：** 如果你和领导谈过 2 次以上，每次都有各种理由（没预算/再等等/还需要提升），但从来没有给你明确的时间线和标准——大概率是不想给你涨。此时你有两个选择：1) 接受现状，把精力放在成长或副业上；2) 开始看外面的机会，用市场价格验证自己的价值。
