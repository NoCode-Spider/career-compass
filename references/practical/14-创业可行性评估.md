# 14-创业可行性评估

> 适用场景：有创业想法，想评估到底靠不靠谱、要不要行动。
> 目标读者：考虑创业的人。

---

## 一、先说实话：创业的真实数据

### 1.1 失败率

| 时间 | 失败率 |
|------|--------|
| 1 年 | ~20% |
| 3 年 | ~50% |
| 5 年 | ~70% |
| 10 年 | ~90% |

**90% 的创业公司活不过 10 年。** 这不是吓你，是让你有现实预期。

### 1.2 最常见的失败原因（CB Insights 调查）

| 原因 | 占比 |
|------|------|
| 没有市场需求 | 42% |
| 现金流断裂 | 29% |
| 团队不合适 | 23% |
| 被竞争对手打败 | 19% |
| 定价/成本问题 | 18% |
| 产品糟糕 | 17% |
| 商业模式不行 | 17% |
| 营销不行 | 14% |
| 忽视客户 | 14% |
| 时机不对 | 10% |

**最大的原因不是"产品不好"不是"团队不行"，是**"没人需要"**。**

## 二、创业可行性评估

### 2.1 你适不适合创业

| 特质 | 适合创业 | 不适合创业 |
|------|---------|-----------|
| 风险承受 | 能接受失败，输得起 | 输不起，有房贷/家庭/固定支出 |
| 主动性 | 自己找事做，不需要别人推 | 需要别人安排才做事 |
| 抗压能力 | 高压下还能做决策 | 压力大就崩溃/失眠 |
| 不确定性 | 享受探索和未知 | 需要确定性和安全感 |
| 学习能力 | 快速学新东西，不断迭代 | 习惯按部就班 |
| 社交能力 | 能卖东西、能找人、能谈判 | 极度社恐 |
| 经济基础 | 至少 1-2 年生活费储备 | 月光，下个月房租都没着落 |

### 2.2 你的想法靠不靠谱

在投入任何资源之前，回答这 10 个问题：

1. **你解决的是什么问题？** — 用一句话说清楚
2. **谁有这个问题？** — 具体到人群画像
3. **这个问题有多痛？** — 是"有了更好"还是"没有不行"？
4. **现在他们怎么解决这个问题？** — 替代方案是什么？
5. **你的解决方案是什么？** — 比现有方案好多少？
6. **为什么是你来做？** — 你有什么独特优势？
7. **怎么赚钱？** — 谁付钱？付多少？
8. **市场有多大？** — 粗略估算就行
9. **竞争对手是谁？** — 不要说"没有竞争对手"，那通常意味着没有市场
10. **最坏情况是什么？你能接受吗？** — 赔多少钱/多长时间你能承受

## 三、最小可行验证（MVP）

### 3.1 为什么要验证

大多数创业失败是因为"花了很多钱做了一个没人要的产品"。验证的目的是：**用最少的钱和时间，确认"有人愿意付费"这个核心假设。**

### 3.2 验证四步法

#### 第一步：需求验证（1-2 周，成本 < 1000 元）

**目标：** 确认真的有人有这个问题，而且够痛。

**方法：**
- 找 50 个目标用户做访谈（线上/线下）
- 问痛点，不问解决方案（不要说"我有个产品你要不要"，要说"你有什么困扰"）
- 如果 50 个人里有超过 20 个人说"这真的是我的大问题"——继续
- 如果大家都说"还好吧，没那么严重"——停，换方向

#### 第二步：兴趣验证（2-4 周，成本 < 5000 元）

**目标：** 确认有人愿意为解决方案付钱。

**方法：**
- 做一个落地页/宣传文案，描述你的产品/服务和价格
- 投放给目标用户（朋友圈/社群/少量广告）
- 看有多少人表示"想买"/"想了解"
- 甚至可以收"预购定金"——真金白银的意愿才是真的
- 转化率 > 5% 算不错

#### 第三步：手动服务验证（1-3 个月，人力成本）

**目标：** 确认你真的能交付，且客户满意。

**方法：**
- 不用做产品/系统，先手动服务第一批客户
- 价格可以低一点，甚至免费
- 核心是验证：交付流程能不能跑通？客户满不满意？愿不愿意推荐？
- 有 5-10 个满意客户了，再考虑规模化

#### 第四步：产品化/规模化（3-6 个月）

**目标：** 把手动服务变成可复制的产品/服务。

**方法：**
- 做最小可行产品（MVP）
- 跑通获客→转化→交付→复购的全流程
- 验证单位经济模型（获客成本 < 客户终身价值）

### 3.3 常见验证误区

| 误区 | 正确做法 |
|------|---------|
| "我先做出来再说" | 先验证需求，再做产品 |
| "我朋友都说好" | 朋友的话不算数，找陌生人验证 |
| "有人说想要就是有需求" | 说想要≠愿意付钱。收钱才是真验证 |
| "我要做一个完美的产品" | MVP 的 P 是 Minimum 不是 Perfect |
| "验证了一次就够了" | 持续验证，每个阶段验证不同的假设 |

## 四、创业前准备

### 4.1 资金规划

| 类别 | 说明 | 估算 |
|------|------|------|
| **启动资金** | 注册、办公、初始投入 | 因人/行业而异 |
| **生活费** | 至少 12-24 个月 | 月支出 × 12~24 |
| **运营资金** | 前 6-12 个月的运营成本 | 月运营成本 × 6~12 |
| **缓冲资金** | 意外支出 | 以上总和 × 20% |

**原则：** 永远比你以为需要的钱多准备 50%——创业的钱永远比你想的花得快。

### 4.2 团队

| 阶段 | 需要什么样的人 |
|------|---------------|
| 0-1 | 创始人自己 + 1-2 个合伙人（互补型） |
| 1-10 | 核心团队，每个人都能独当一面 |
| 10-50 | 开始有中层管理 |

**合伙人选择原则：**
- 能力互补（你不懂的他懂）
- 价值观一致（钱怎么分、事怎么定、失败了怎么办）
- 全职投入（兼职合伙大概率出问题）
- 信任基础（最好是一起共过事的）

### 4.3 法律和合规

- 注册公司类型（个体户/有限责任公司/合伙企业）
- 股权分配（不要 50/50，要有一个人说了算）
- 合伙人协议（退出机制、股权成熟）
- 知识产权归属
- 税务问题
- **建议：咨询专业律师和会计，不要省这个钱**

## 五、什么时候不该创业

| 情况 | 为什么不该 |
|------|-----------|
| 为了逃避打工 | 创业比打工累 10 倍，逃避式创业大概率失败 |
| 因为"大家都在创业" | 跟风的大多成了分母 |
| 有一个"绝妙的点子" | 点子不值钱，执行才值钱 |
| 没钱没积蓄 | 没钱会让你做很多错误决策（为了短期收入牺牲长期） |
| 家庭负担重 | 上有老下有小，输不起 |
| 你讨厌现在的老板 | 换个工作就行，犯不着创业 |
| 想"时间自由" | 创业是 24 小时 on call，比打工还不自由 |

## 六、创业决策清单

- [ ] 我解决的问题是真实存在的（不是我想象的）
- [ ] 我和 50+ 个目标用户聊过
- [ ] 我做了最小验证，有人愿意付钱
- [ ] 我有明确的盈利模式（不是"以后再说"）
- [ ] 我有 12 个月以上的生活费储备
- [ ] 我能接受最坏情况（赔光时间和钱）
- [ ] 我有合适的合伙人/团队（或确定可以 solo 起步）
- [ ] 我了解行业和竞争对手
- [ ] 我不是为了逃避打工，而是真的想做这件事
- [ ] 我做好了长期奋战的准备（不是"做一年就上市"）

**打勾 < 5 个：** 再想想，可能还没准备好
**打勾 5-8 个：** 可以开始小规模验证
**打勾 9-10 个：** 可以开始干了

---

> **停止条件：** 如果你已经验证了 6 个月，花了不少钱和时间，但还是找不到付费用户（或用户留存极低），可能这个方向真的不对。及时止损不是失败，是智慧。创业本来就是一个不断假设-验证-调整的过程，方向不对就换，比死磕到底聪明。
