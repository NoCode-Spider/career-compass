# 03-薪酬谈判实战指南

> 适用场景：拿到 offer 后谈薪，或在职要求加薪。
> 目标读者：有 offer 在手或准备谈薪的职场人。

---

## 一、薪酬谈判的核心原则

### 1.1 谈判的本质

薪酬谈判不是"讨价还价"，而是**基于市场价值的合理协商**。公司给你的不是"你值多少钱"，而是"他们需要付多少钱才能留住你"。你的目标是：**在不破坏关系的前提下，争取到对自己最有利的薪酬包**。

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| **永远不要先出价** | 先让对方说预算，你再根据对方报价调整 |
| **谈总包不谈月薪** | 月薪只是一部分，看整体package |
| **用数据说话** | 引用市场数据，不是"我觉得我值更多" |
| **不要只谈钱** | 成长机会、职级、福利、弹性都是筹码 |
| **保持礼貌和专业** | 谈判是合作不是对抗，态度决定关系 |

## 二、谈前准备

### 2.1 市场调研

| 调研渠道 | 适合什么 | 使用方法 |
|---------|---------|---------|
| BOSS 直聘/拉勾 | 市场区间参考 | 搜同城市同岗位同经验，看薪资范围 |
| 脉脉 | 大厂薪资 | 看"职言"区的薪资爆料（注意真实性） |
| Levels.fyi | 外企/海外 | 全球科技公司薪资数据 |
| 行业薪酬报告 | 宏观参考 | Deloitte/Mercer 年度薪酬报告 |
| 朋友/同行 | 最准确 | 礼貌询问同行业朋友的薪资范围 |

**调研目标：** 确定三个数字——
- **底线**：低于这个就不考虑（基于生活成本和当前收入）
- **目标值**：你认为合理且满意的数字
- **理想值**：拿到会特别开心的数字（敢说出来就行）

### 2.2 了解薪酬结构

在谈之前，先搞清楚对方的薪酬构成：

| 组成 | 要问清楚的 |
|------|-----------|
| 基本月薪 | 多少？发几个月？ |
| 绩效/奖金 | 怎么算？平均能拿多少？ |
| 股票/期权 | 多少？分几年？行权价？ |
| 补贴 | 餐补/交通/住房？ |
| 公积金 | 缴纳比例？有没有补充公积金？ |
| 社保 | 按实际工资还是最低基数？ |
| 假期 | 年假多少天？ |
| 其他福利 | 体检/保险/学习预算？ |

## 三、offer 谈判话术

### 3.1 对方先问期望薪资

**策略：给范围，不给精确数。范围的下限是你的目标值。**

**话术 1（稳健版）：**
> "我对这个岗位的薪资预期是在 20K-25K 之间，具体可以根据公司的薪酬结构和职责范围再协商。"

**话术 2（反问版）：**
> "我想先了解一下公司这个岗位的薪酬预算大概是多少？这样我可以更准确地评估。"

**话术 3（灵活版）：**
> "薪资不是我最看重的因素，我更看重岗位本身的发展机会。当然也希望薪酬能和我的经验和能力匹配，大概在市场水平的中上位置就可以。"

### 3.2 对方给了 offer，你想往上谈

**策略：先表达兴趣，再提期望，给理由。**

**话术 1（市场数据版）：**
> "非常感谢这个 offer，我对这个岗位很感兴趣。关于薪资，我了解到同行业同岗位 3 年经验的市场水平大概在 22K-28K 之间，我的期望是 25K。不知道这个范围公司这边有没有调整空间？"

**话术 2（强调价值版）：**
> "谢谢 offer，我对团队和方向都很认可。关于薪酬，我目前的总包大概是 30 万，我期望能有 20% 左右的增长，也就是 36 万左右。主要考虑到我在[核心技能/项目经验]方面能给团队带来的价值。您看这个期望有没有可能调整？"

**话术 3（备选方案版）：**
> "薪资方面，我理解公司有固定的薪酬体系。如果基本工资调整空间有限，能不能在其他方面考虑一下？比如签字费、股票或者职级上？"

### 3.3 谈不上去怎么办

**策略：不要只盯着月薪，看总包和非货币因素。**

| 可谈的替代项 | 说明 |
|------------|------|
| 签字费 | 一次性补偿，常见于大厂 |
| 股票/期权增加 | 长期价值 |
| 试用期缩短 | 提前拿全额工资 |
| 职级上调 | 影响后续加薪和晋升 |
| 入职评级提升 | 对应更高的薪酬带宽 |
| 补充公积金 | 隐性收入 |
| 学习预算 | 个人成长投入 |
| 更多年假 | — |
| 弹性工作 | 远程/灵活时间 |

### 3.4 最终确认

谈妥后，一定要确认以下信息再接受：

- [ ] 基本工资（税前/税后？）
- [ ] 薪资发放月数（13 薪/14 薪？）
- [ ] 奖金计算方式（个人/团队/公司绩效？比例？）
- [ ] 试用期薪资（全额还是 80%？）
- [ ] 试用期时长
- [ ] 股票/期权数量和归属计划
- [ ] 公积金缴纳基数和比例
- [ ] 社保缴纳基数
- [ ] 年假天数
- [ ] 入职时间
- [ ] 其他福利（体检/保险/餐补等）

## 四、在职加薪谈判

### 4.1 什么时候提

| 好时机 | 不好的时机 |
|--------|-----------|
| 刚完成一个重大项目后 | 公司业绩不好/裁员时 |
| 绩效周期前 | 老板特别忙的时候 |
| 承担了更多职责后 | 刚犯了一个错误后 |
| 有外部 offer 时（慎用） | 仅仅因为"别人都涨了我没涨" |

### 4.2 加薪谈判话术

**话术 1（成果导向型）：**
> "老板，我想和您聊聊我的薪资。过去这一年，我主要负责了[项目 A]和[项目 B]，分别取得了[量化成果 A]和[量化成果 B]的成绩。现在我的职责也比入职时增加了不少，比如[新增职责]。基于这些，我希望薪资能有 20% 左右的调整。您觉得怎么样？"

**话术 2（发展导向型）：**
> "老板，我想和您聊聊我的职业发展。我在公司 X 年了，这期间成长了很多，也做了[成果]。我希望能在薪酬上得到相应的认可，这样我也能更安心地长期投入。您看我目前的发展路径和薪资调整大概是什么节奏？"

### 4.3 如果被拒绝

- **原因是"公司政策"**：问清楚下一次调薪时间和条件，设定明确目标
- **原因是"业绩不够"**：问清楚具体差距在哪里，制定改进计划
- **原因是"预算不够"**：探讨非现金补偿（职级、学习预算、更多假期）
- **不要威胁离职**：除非你真的准备好了，否则不要用离职当筹码

## 五、跳槽涨幅参考

### 5.1 合理涨幅范围

| 跳槽类型 | 合理涨幅 | 说明 |
|---------|---------|------|
| 平级跳同行业 | 15-30% | 最常见 |
| 升级跳（晋升） | 30-50% | 岗位升级 |
| 跨行跳 | 0-20% | 可能为转行接受降薪 |
| 大厂跳小厂 | 20-50% | 小厂通常需要溢价吸引 |
| 小厂跳大厂 | 0-20% | 大厂品牌溢价，可能不涨甚至略降 |
| 有 offer 在手谈 current | 10-20% | 用外部 offer 谈当前公司加薪 |

### 5.2 不要只看涨幅

- 大厂 10% 涨幅可能比小厂 30% 涨幅绝对值还高
- 底薪 20% 涨幅 vs 总包 10% 涨幅——可能后者更高
- 稳定性、成长性、工作生活平衡都是"隐性薪酬"

## 六、常见误区

| 误区 | 正确做法 |
|------|---------|
| "谈薪会影响关系" | 专业的谈判不会破坏关系，反而展示你的价值感 |
| "第一次给的就是最终价" | 大多数公司都留了谈判空间 |
| 只看月薪 | 看总包，看长期 |
| 用生活成本当理由 | 用市场价值和你能带来的价值当理由 |
| 不好意思开口 | 公司给你开价时也没不好意思 |
| 拿到 offer 当场答应 | 争取 1-2 天考虑时间，不要当场拍板 |
| 漫天要价 | 在合理范围内，离谱的报价会显得不专业 |

## 七、谈判决策清单

谈判前完成以下准备：

- [ ] 做了市场调研，知道市场区间
- [ ] 确定了自己的底线/目标/理想值
- [ ] 了解了对方的薪酬结构
- [ ] 准备了 2-3 个谈判理由（成果/技能/市场数据）
- [ ] 准备了替代方案（如果薪资谈不动，可以谈什么）
- [ ] 想清楚了最看重什么（钱/成长/稳定/弹性）
- [ ] 给自己留了考虑时间（不当场答应）
- [ ] 全程保持礼貌和专业

---

> **停止条件：** 如果谈了两轮以上还是没达到你的底线，且替代方案也无法弥补，说明这个 offer 可能不适合你——礼貌拒绝，继续找下一个。不要因为"面了好久舍不得"而接受不满意的 offer——入职后的不满会比拒绝的遗憾更持久。
