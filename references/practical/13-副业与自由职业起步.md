# 13-副业与自由职业起步

> 适用场景：想发展副业、尝试自由职业，但不知道从哪开始。
> 目标读者：有全职工作、想额外增加收入或探索可能性的人。

---

## 一、先搞清楚：你适合做副业/自由职业吗

### 1.1 自我评估

| 维度 | 适合的表现 | 不适合的表现 |
|------|-----------|-------------|
| **时间** | 每天能挤出 1-2 小时，周末有时间 | 每天下班只想躺平，完全没精力 |
| **自律** | 能自己安排时间、自己推动自己 | 需要别人管着才做事 |
| **技能** | 有一项能卖钱的技能（或能快速学会） | 不知道自己能卖什么 |
| **风险承受** | 能接受前 3-6 个月没收入 | 投了时间就要马上看到回报 |
| **社交能力** | 能主动联系客户、推销自己 | 极度社恐，不敢谈钱 |
| **经济压力** | 有主业收入，副业是额外的 | 急需用钱，把副业当救命稻草 |

### 1.2 副业的三种心态

| 心态 | 目标 | 适合的人 |
|------|------|---------|
| **赚零花钱** | 每月多赚 1-3k | 时间不多，想补充收入 |
| **技能变现 + 探索** | 验证技能市场价值，探索方向 | 不确定未来方向，想试水 |
| **替代主业** | 最终成为自由职业/创业 | 有明确方向，想逐步脱离打工 |

**不要一开始就想"替代主业"——先从赚零花钱开始验证可行性。**

---

## 二、什么能当副业

### 2.1 副业类型总览

| 类型 | 例子 | 门槛 | 收入天花板 | 时间灵活度 |
|------|------|------|-----------|-----------|
| **技能服务型** | 设计/写作/翻译/编程/咨询 | 中 | 中高 | 高 |
| **内容创作型** | 公众号/视频/播客/小红书 | 低 | 高（但慢） | 高 |
| **电商型** | 淘宝/闲鱼/跨境电商 | 中 | 中高 | 中 |
| **知识付费型** | 课程/社群/咨询 | 中高 | 高 | 高 |
| **体力型** | 外卖/网约车/代驾 | 低 | 低 | 高 |
| **投资型** | 理财/房产/股票 | 高（需要本金） | 不定 | 低 |

### 2.2 从主业技能延伸（成功率最高）

副业最容易成功的方式是**把主业技能包装成服务卖出去**——你已经会了，不需要从零学。

| 主业 | 可以做的副业 |
|------|-------------|
| 设计师 | 接设计单、做设计教程、卖模板 |
| 程序员 | 接外包、做独立产品、技术咨询 |
| 运营 | 代运营、咨询、做社群 |
| 文案 | 代写文案、做公众号、出书 |
| 老师/培训 | 做在线课程、1 对 1 辅导 |
| 财务 | 代账、财务咨询 |
| HR | 简历优化、面试辅导、职业咨询 |

### 2.3 怎么选

- **从你已经会的出发**：不要为了做副业去学一个全新的技能
- **市场有需求的**：有人愿意付钱，才叫副业
- **你喜欢/不排斥的**：副业本来就是额外精力做的，不喜欢坚持不下去
- **时间可控的**：不要搞成比主业还累

## 三、起步三步法

### 第一步：确定卖什么（1-2 周）

- 列出你的技能清单（用 KSAO 盘点，参见实用指南 07）
- 筛选出"能卖钱"的技能
- 选一个你最有信心的，就一个——不要同时做好几个

### 第二步：最小产品化（2-4 周）

不要等"准备好"再开始，先做一个最小版本试试：

| 副业类型 | 最小产品 |
|---------|---------|
| 设计服务 | 一个作品集页面 + 3 个代表作品 |
| 写作/文案 | 3 篇作品样稿 |
| 咨询服务 | 一个清晰的服务介绍 + 价格 |
| 内容创作 | 先发 10 篇/条内容看看反馈 |
| 课程 | 先做 1 节试听课 |

**核心原则：** 先验证"有人愿意买"，再投入更多时间。

### 第三步：获取第一个客户（1-2 个月）

| 获客渠道 | 怎么做 | 适合谁 |
|---------|--------|--------|
| **朋友圈/熟人** | 告诉朋友你在做这个，问有没有需要 | 所有人（起步最快） |
| **垂直平台** | 站酷/花瓣（设计）、掘金/思否（技术）、小红书（生活类） | 有作品展示的 |
| **接单平台** | 猪八戒、一品威客、Upwork、Fiverr | 服务型副业 |
| **内容引流** | 知乎/小红书/公众号输出专业内容 | 有耐心长期做的 |
| **社群** | 行业群里活跃，建立专业形象 | 有行业人脉的 |

**第一个客户怎么找：**
- 从熟人开始——告诉 10 个朋友你在做这件事
- 第一个客户可以便宜一点，甚至免费——重点是拿到案例和反馈
- 满意的客户是最好的宣传员（转介绍）

## 四、定价策略

### 4.1 新手怎么定价

| 定价策略 | 做法 | 适用阶段 |
|---------|------|---------|
| **低于市场** | 比市场价低 30-50%，快速积累案例 | 起步期（0-5 个客户） |
| **市场价** | 和市场价持平 | 成长期（5-20 个客户） |
| **高于市场** | 靠口碑和专业度溢价 | 成熟期 |

### 4.2 常见定价误区

| 误区 | 正确做法 |
|------|---------|
| "我是新手所以应该便宜" | 可以便宜，但不要便宜到自己觉得亏——做起来没动力 |
| "按时间收费" | 能按项目收费就按项目，不要按小时——你做得快是你厉害 |
| "不好意思谈钱" | 你提供价值，收钱是应该的。不好意思就先从明码标价开始 |
| "越便宜越多人买" | 太低的价格会让人怀疑质量 |

## 五、注意事项和风险

### 5.1 合规风险

| 风险 | 说明 | 怎么规避 |
|------|------|---------|
| **违反劳动合同** | 很多公司规定不能做兼职/同业竞争 | 看劳动合同，避开和主业有竞争的领域 |
| **税务问题** | 副业收入也要报税 | 年收入高了要自行申报 |
| **知识产权** | 用公司资源做的副业可能归公司 | 用自己的设备、自己的时间、自己的资源 |
| **影响主业** | 副业占用太多精力影响主业表现 | 设定时间上限，主业优先 |

### 5.2 常见坑

| 坑 | 怎么避免 |
|----|---------|
| **交加盟费/培训费** | 凡是让你先交钱的"副业"大概率是割韭菜 |
| **刷单/打字员** | 99% 是骗局 |
| **一开始投入很多钱** | 副业原则：先赚钱再投钱，不是反过来 |
| **贪多求全** | 什么都想做，什么都做不好。先专注一个 |
| **三天打鱼两天晒网** | 副业是长期的，前 3 个月没收入很正常 |

## 六、从副业到自由职业

### 6.1 什么时候可以考虑全职做

- [ ] 副业稳定收入 ≥ 主业收入的 70%
- [ ] 持续 3 个月以上（不是偶尔一个月）
- [ ] 有稳定的客户来源（不是只靠一个客户）
- [ ] 有 6 个月以上生活费储备
- [ ] 你确定这是你想长期做的
- [ ] 社保/公积金问题有解决方案

### 6.2 自由职业的隐性成本（重要！）

不要只看"时薪比上班高"，这些成本要算进去：

| 成本 | 说明 |
|------|------|
| 社保公积金 | 自己全额交（公司那部分也要自己出） |
| 无薪假期 | 休息=没收入 |
| 获客成本 | 自己找客户的时间和钱 |
| 不稳定收入 | 好月和差月差很多 |
| 没有公司资源 | 设备、软件、培训全部自己掏 |
| 孤独感 | 没有同事和团队 |
| 缺乏成长反馈 | 没有人带你、评价你 |

**粗略估算：** 自由职业要达到和上班同样的生活质量，收入需要比上班高 40-60%。

---

## 七、起步清单

- [ ] 我确定了副业方向（从已有技能出发）
- [ ] 我做了最小产品/作品集
- [ ] 我研究了市场价格，定了自己的定价
- [ ] 我告诉了 10 个以上的朋友我在做这件事
- [ ] 我选了 1-2 个获客渠道开始行动
- [ ] 我设定了时间上限（不影响主业）
- [ ] 我了解了合规风险（劳动合同/税务）
- [ ] 我有心理准备——前 3 个月可能没收入
- [ ] 我不打算一开始就投很多钱
- [ ] 我给自己定了一个试错期限（如 6 个月）

---

> **停止条件：** 如果你做了 6 个月以上，投入了大量时间但还没赚到一分钱（或赚的钱低于 1000/月），可能方向不对或方法不对——停下来复盘：是方向选错了？是获客渠道不对？还是定价有问题？如果调整了还是不行，及时止损，换个方向。
