# 11-职业倦怠自救指南

> 适用场景：上班像上坟、提不起劲、对什么都没兴趣、经常感到疲惫。
> 目标读者：倦怠感明显但还在坚持的职场人。

> **重要提醒：** 如果持续两周以上全面兴趣丧失（不止对工作，对一切都没兴趣），或有自我伤害念头，可能是抑郁，不是倦怠——请立即寻求专业心理帮助。

---

## 一、你倦怠了吗

### 1.1 倦怠三维度自检

| 维度 | 表现 | 你的程度（1-5分） |
|------|------|-----------------|
| **情感耗竭** | 上班觉得累，下班更累；早上想到上班就不想起 | ___ |
| **去人格化** | 对工作麻木，觉得"就这样吧"；对同事/客户不耐烦 | ___ |
| **成就感降低** | 觉得自己做的事没意义；怀疑自己的能力 | ___ |

**评分说明：**
- 3-5 分：轻度倦怠 — 需要调整
- 8-10 分：中度倦怠 — 认真对待，需要系统性改变
- 12-15 分：重度倦怠 — 强烈建议休息，考虑就医或专业咨询

### 1.2 倦怠 vs 抑郁

| 维度 | 倦怠 | 抑郁 |
|------|------|------|
| **范围** | 主要在工作领域 | 影响所有生活领域 |
| **核心感受** | 累、麻木 | 低落、无意义、自责 |
| **兴趣** | 对工作没兴趣，生活中还有 | 对什么都没兴趣 |
| **睡眠** | 累但能睡（或不想起） | 失眠或嗜睡，早醒 |
| **自我价值** | 怀疑工作能力 | 全面否定自己 |
| **自杀念头** | 通常没有 | 可能有 |
| **改善方式** | 调整工作/休息 | 需要专业治疗 |

**如果有以下情况，请寻求专业帮助：**
- [ ] 对以前喜欢的事也完全没兴趣了
- [ ] 持续两周以上每天大部分时间情绪低落
- [ ] 严重失眠或嗜睡
- [ ] 觉得活着没意思，或有自我伤害念头

## 二、紧急救援：72 小时恢复法

如果你现在已经快撑不住了，先做这三件事：

### 第 1 天：停下来
- 请 1 天病假（哪怕你觉得"不严重"）
- 不看工作消息，不想工作的事
- 睡够觉，想吃什么吃什么
- 看一部无脑电影或玩游戏
- **目的：** 先从持续耗竭的状态中抽出来

### 第 2 天：搞清楚状况
- 拿一张纸，写下来：
  - 工作中哪些事最让你累？（列 3-5 件）
  - 这些事占了你多少时间？
  - 有没有可能减少/ delegated/ 优化？
  - 哪些是完全没法改变的？
- **目的：** 从"好累啊"的模糊感受，变成具体的问题清单

### 第 3 天：做一个小改变
- 从上面的清单里，挑一个**最小、最容易改**的事
- 只改这一件，其他先不动
- 比如：每天 6 点准时下班，不加班
- 比如：每天中午必须离开工位去吃饭散步
- **目的：** 找回一点控制感——你不是完全无能为力的

## 三、JD-R 自救策略

根据 JD-R 模型（见知识库 05），倦怠来自"要求太高 + 资源太少"。自救就是**减要求 + 加资源**。

### 3.1 减要求（降低消耗）

| 策略 | 怎么做 | 难度 |
|------|--------|------|
| **设定边界** | 到点下班，周末不看工作消息 | 中 |
| **优先级排序** | 只做重要的事，不重要的推掉或拖延 | 中 |
| **降低完美主义** | "完成比完美重要"，80 分就够了 | 中高 |
| **减少无效社交** | 不必要的饭局/闲聊能推就推 | 低 |
| **Delegation** | 能交给别人做的就交出去 | 高（看权限） |
| **减少信息输入** | 关掉工作群消息提醒，固定时间看 | 低 |

### 3.2 加资源（补充能量）

| 策略 | 怎么做 | 难度 |
|------|--------|------|
| **寻求支持** | 和领导聊，争取资源或调整预期 | 中 |
| **找导师** | 找一个有经验的前辈请教 | 中 |
| **技能提升** | 能力提升了，同样的事消耗更少 | 高 |
| **社交充电** | 和朋友/家人高质量相处 | 低 |
| **运动** | 每周 3 次 30 分钟运动（亲测有效） | 中 |
| **爱好** | 有一件和工作完全无关的事能让你投入 | 低 |
| **睡眠** | 保证 7 小时以上睡眠 | 中 |

## 四、工作重塑

如果倦怠是因为工作本身的设计问题（JCM 五特征低），可以尝试工作重塑。

### 4.1 三种工作重塑方式

| 类型 | 做法 | 例子 |
|------|------|------|
| **任务重塑** | 改变工作内容的数量/种类/方式 | 主动承担一个你感兴趣的新项目 |
| **关系重塑** | 改变工作中的人际关系 | 找一个 mentor，或参加跨部门项目 |
| **认知重塑** | 改变对工作意义的看法 | "我写代码"→"我做的产品帮助了百万用户" |

### 4.2 认知重塑练习

拿一张纸，写下：

1. 我当前的工作是：________
2. 这份工作影响到的人有：________
3. 如果没有我做这份工作，会有什么影响：________
4. 这份工作对我自己的意义是：________

**目的：** 不是强行"爱上工作"，而是从"我只是个螺丝钉"的视角，看到工作的影响链——任务重要性（JCM）低的人，更容易倦怠。

## 五、什么时候该考虑离开

### 5.1 该走的信号

- [ ] 尝试了 3 个月以上的自救策略，没有改善
- [ ] 倦怠已经影响到身体健康（失眠、免疫力下降、情绪失控）
- [ ] 工作环境没有任何改变的可能（领导不变、制度不变、业务不变）
- [ ] 你已经不是"累"，而是"麻木"——对什么都没感觉
- [ ] 出现了抑郁信号（见 1.2）

### 5.2 离开前的准备

如果决定走，不要裸辞——按以下步骤：

1. **先休息**：能请病假请病假，能休年假休年假，先把状态调整好
2. **盘点存款**：至少 6 个月生活费
3. **更新简历**：状态好一点的时候再写，倦怠期写的简历没精神
4. **骑驴找马**：在职慢慢看，不要急
5. **下一份工作避坑**：分析这次倦怠的原因，下一份工作尽量避开同样的坑

## 六、日常防倦怠清单

每天/每周做这些小事，预防倦怠：

**每天：**
- [ ] 中午离开工位吃饭，不边吃边工作
- [ ] 下班前 10 分钟做个收尾，不把工作焦虑带回家
- [ ] 到家后先换衣服/洗澡，从物理上切换状态
- [ ] 睡前 1 小时不看工作消息

**每周：**
- [ ] 至少运动 2 次（30 分钟以上）
- [ ] 至少有 1 天完全不碰工作
- [ ] 和朋友/家人有一次高质量相处
- [ ] 做一件和工作完全无关的、能让你投入的事

**每月：**
- [ ] 做一次状态自评（倦怠三维度打分）
- [ ] 如果分数在升高，及时调整，不要等崩了再说

## 七、常见误区

| 误区 | 正确认知 |
|------|---------|
| "倦怠是我不够坚强" | 倦怠是工作环境问题，不是个人性格问题 |
| "休个假就好了" | 休假只能暂时缓解，回来还是一样会倦怠 |
| "忙完这阵就好了" | 忙完这阵还有下一阵，永远有"这阵" |
| "别人都能扛我为什么不能" | 每个人的阈值不同，不需要和别人比 |
| "换一份工作就好了" | 不一定，如果是自身模式问题，换了还会倦怠 |
| "我就是懒" | 你不是懒，你是累了。倦怠是真实的，不是矫情 |

---

> **停止条件：** 如果你已经尝试自救 3 个月以上，倦怠程度没有减轻甚至加重，且工作环境无法改变——不要再硬撑了。身体和心理健康比一份工作重要。该休息休息，该换工作换工作，该看医生看医生。
