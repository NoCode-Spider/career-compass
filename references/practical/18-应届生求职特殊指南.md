# 18-应届生求职特殊指南

> 适用场景：应届毕业生找第一份工作。
> 目标读者：大四/研三应届生、即将毕业的学生。

---

## 一、应届生的优劣势

### 1.1 你的优势和劣势

| 优势 | 劣势 |
|------|------|
| 年轻、学习能力强 | 没经验 |
| 可塑性强 | 不知道自己适合什么 |
| 有冲劲、肯吃苦 | 职业认知模糊 |
| 企业愿意培养（成本低） | 选择多反而容易迷茫 |
| 试错成本低 | 容易被忽悠 |

### 1.2 应届生找工作的时间线

| 时间 | 阶段 | 做什么 |
|------|------|--------|
| **大三下/研二下** | 准备期 | 确定方向、找实习、攒经历 |
| **暑假** | 实习黄金期 | 做一份有质量的实习 |
| **9-11 月** | 秋招 | 校招黄金期，大量机会 |
| **12-1 月** | 秋招尾声 | 补录、面试、拿 offer |
| **2-4 月** | 春招 | 补招、考研/考公失利的人加入战场 |
| **5-6 月** | 毕业季 | 入职前准备 |

**重点：秋招是机会最多的时候，一定要抓住。**

## 二、找什么工作

### 2.1 应届生常见的迷茫

- "我不知道自己喜欢什么"
- "我不知道自己能做什么"
- "大家都在考公/考研/进互联网，我要不要也去"
- "这份工作是不是好工作？"

### 2.2 怎么选方向

#### 方法一：从专业出发

| 策略 | 做法 | 适合谁 |
|------|------|--------|
| **专业对口** | 找和专业直接相关的工作 | 喜欢本专业的 |
| **专业相关** | 找用到专业知识但不直接对口的 | 不讨厌本专业但想扩展的 |
| **完全跨专业** | 找和专业没关系的 | 确定不喜欢本专业的 |

#### 方法二：从兴趣/性格出发

参考 Holland 职业兴趣理论（见知识库 01），但注意：
- 兴趣可以培养
- 很多工作你没做过不知道自己喜不喜欢
- 不要因为"感兴趣"就忽略现实因素（薪资、发展、需求）

#### 方法三：排除法

不知道想要什么很正常，但你大概知道自己**不想要**什么。

- 我不想做什么？（比如：不想做销售、不想加班太多、不想太稳定）
- 我不能接受什么？（比如：不能接受太低的工资、不能接受异地）
- 排除掉完全不能接受的，剩下的都可以试试

### 2.3 第一份工作看重什么

按重要性排序：

| 优先级 | 因素 | 说明 |
|--------|------|------|
| 1 | **行业/赛道** | 男怕入错行，女也怕。选对行业比选对公司重要 |
| 2 | **公司平台** | 大公司的背书和体系化培养，对新人很重要 |
| 3 | **能不能学到东西** | 第一份工作，成长比工资重要 |
| 4 | **直属领导** | 跟对人比进对公司重要 |
| 5 | **薪资** | 重要，但不是最重要的 |
| 6 | **城市** | 看个人选择和家庭情况 |
| 7 | **工作内容** | 新人做什么其实不太重要，都是从基础做起 |
| 8 | **同事好不好** | 加分项，不是决定项 |

## 三、简历

### 3.1 没经验怎么写简历

应届生没经验很正常，但你可以写这些：

- **实习经历**（最重要）
- **项目经历**（课程项目、竞赛、个人项目）
- **校园经历**（学生会、社团、班委——挑有亮点的写）
- **技能证书**（语言、计算机、专业证书）
- **教育背景**（学校、专业、GPA——高就写，不高就不写）
- **自我评价**（不要写"性格开朗、学习能力强"这种空话）

### 3.2 STAR 写经历

每条经历用 STAR 结构写：

- **S**ituation：背景是什么
- **T**ask：你的任务是什么
- **A**ction：你做了什么
- **R**esult：结果怎么样（**用数据**）

**❌ 错误写法：**
> "负责公众号运营"

**✅ 正确写法：**
> "运营班级公众号，从 0 开始搭建，3 个月涨粉 500+，单篇阅读最高 2000+，打开率 35%。"

### 3.3 简历常见问题

| 问题 | 怎么办 |
|------|--------|
| 学校不好 | 突出实习/项目/技能，学校放下面 |
| 成绩不好 | 不写 GPA，或者只写相关课程 |
| 没实习 | 做一个相关的个人项目/竞赛，写进简历 |
| 没什么可写的 | 深挖！任何经历都有亮点，看你怎么表达 |
| 简历只有半页 | 宁可半页真实的，也不要凑一页废话 |

## 四、找实习

### 4.1 为什么实习重要

- 有实习经验的应届生找工作容易 3 倍以上
- 实习是你了解行业/公司的最好方式
- 很多公司实习可以转正（最省力的找工作方式）
- 实习可以攒作品/项目经验

### 4.2 怎么找实习

| 渠道 | 说明 |
|------|------|
| **学长学姐推荐** | 最有效，成功率高 |
| **实习僧/刺猬实习** | 专门的实习平台 |
| **公司官网/公众号** | 大公司有专门的实习招聘 |
| **社群/朋友圈** | 很多实习机会是内部发的 |
| **海投** | 效率低，但可以试试 |

### 4.3 第一份实习不好找怎么办

- 降低要求——小公司也行，有总比没有强
- 免费/低价也可以做——第一份实习是攒经验不是赚钱
- 远程实习也行——至少有东西写进简历
- 自己"造"实习——做一个相关的项目，效果差不多

## 五、校招

### 5.1 秋招 vs 春招

| | 秋招 | 春招 |
|---|------|------|
| **时间** | 9-11 月 | 2-4 月 |
| **岗位数量** | 多（80% 的岗位） | 少（补招为主） |
| **竞争** | 激烈但机会多 | 人少但岗位也少 |
| **质量** | 最好的岗位都在秋招 | 剩下的岗位 |

**能在秋招搞定就不要拖到春招。**

### 5.2 校招流程

```
网申 → 笔试 → 群面 → 技术面/专业面 → HR 面 → 发 offer
```

不同公司不一样，但大致是这个流程。

### 5.3 网申

- 早点投，不要等到截止日期
- 每家公司的简历可以微调，针对岗位调整
- 开放性问题认真写，不要随便复制粘贴
- 内推！内推！内推！（重要的事说三遍）

### 5.4 笔试

- 行测题（逻辑推理、数量关系、言语理解）
- 专业题（和岗位相关）
- 性格测试（如实答就行，不要"装好"）

**准备：** 刷行测题、看面经、复习专业知识。

### 5.5 群面（无领导小组讨论）

群面是校招特有环节，很多人怕。

| 角色 | 适合谁 | 怎么做 |
|------|--------|--------|
| **Leader** | 有领导力、思路清晰的 | 把控方向、分配任务、推进讨论 |
| **Timer** | 细心、时间观念强的 | 计时、提醒时间、推进节奏 |
| **记录者** | 逻辑好、写字快的 | 记录要点、最后总结 |
| **贡献者** | 有想法的普通人 | 提出有质量的观点 |
| **总结者** | 表达好的 | 最后做总结陈述 |

**群面核心：** 不是"说得多就赢"，而是"有贡献、能合作"。

## 六、面试

### 6.1 常见面试问题

**自我介绍（必问）：**
> "我是 XX 学校 XX 专业的应届生。在校期间做了[实习/项目 1]和[实习/项目 2]，主要负责[职责]，取得了[成果]。我对[目标岗位]很感兴趣，因为[原因]。"

**"你为什么选择我们公司/这个岗位？"**
- 说具体的，不要说"因为你们公司大/有名"
- 展示你做过功课（了解公司的业务/产品/文化）
- 把你的能力和岗位要求对应起来

**"你有什么优缺点？"**
- 优点：说和岗位相关的，附例子
- 缺点：说真实但不致命的，且你在改进

**"你还有什么问题要问我吗？"**
- 不要说"没问题"
- 问有质量的问题（团队、业务、成长）
- 不要问薪资假期（HR 面再问）

### 6.2 面试准备

- 了解公司和岗位（官网、公众号、近期新闻）
- 准备 3-5 个自己的故事（用 STAR 准备）
- 模拟面试（找同学练，或者自己对着镜子说）
- 穿得体的衣服（不用太正式，但要干净整洁）
- 提前 10-15 分钟到（不要迟到！）

## 七、offer 选择

### 7.1 多个 offer 怎么选

用决策平衡表（见知识库 02）：

| 因素 | 权重 | Offer A | Offer B | Offer C |
|------|------|---------|---------|---------|
| 行业前景 | 20% | | | |
| 公司平台 | 15% | | | |
| 薪资福利 | 15% | | | |
| 成长空间 | 20% | | | |
| 城市 | 10% | | | |
| 工作内容 | 10% | | | |
| 其他 | 10% | | | |
| **总分** | 100% | | | |

### 7.2 常见纠结

| 纠结 | 建议 |
|------|------|
| 大公司 vs 小公司 | 第一份工作优先大公司（平台、体系、背书） |
| 高薪 vs 成长 | 3 年以内的工作，成长比薪资重要 |
| 喜欢的 vs 赚钱的 | 能选喜欢的当然好，但要确定是真喜欢 |
| 回家 vs 去大城市 | 各有利弊，看你想要什么生活 |
| 稳定 vs 挑战 | 年轻时可以试试挑战，年龄大了求稳 |

## 八、应届生常见坑

| 坑 | 怎么避 |
|----|--------|
| **传销/骗局** | 让你交钱、培训贷、拉人头的都是骗子 |
| **PUA 公司** | 画大饼、灌鸡汤、让你免费加班的 |
| **坑人的培训机构** | "包就业""零基础高薪"都是套路 |
| **签两方就不能违约？** | 可以违约，可能要赔违约金（看合同） |
| **三方协议很重要？** | 影响学校就业率，对你个人影响不大 |
| **试用期工资很低？** | 法律规定试用期工资不低于正式的 80% |

---

## 九、最后想说的

- 第一份工作很重要，但没重要到"决定一生"
- 不用和同学比，每个人节奏不一样
- 选错了也没关系，还年轻，试错成本低
- 工作只是生活的一部分，不是全部
- 保持学习能力，比第一份工作是什么更重要

---

> **停止条件：** 如果你秋招投了几十上百份简历，一个面试都没有——可能是简历问题，也可能是方向问题。停下来改简历，或者调整方向。不要一条路走到黑，先拿到一个 offer 保底，再慢慢找更好的。
