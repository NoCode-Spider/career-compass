# 05-跳槽时机与策略

> 适用场景：考虑要不要跳槽、什么时候跳最合适。
> 目标读者：在职但考虑跳槽的人。

---

## 一、跳槽的时机判断

### 1.1 该跳的信号

| 信号 | 说明 | 紧迫度 |
|------|------|--------|
| **成长停滞** | 连续 1 年以上学不到新东西，技能没有提升 | ⭐⭐⭐ |
| **价值被低估** | 薪酬低于市场 20% 以上，且内部加薪无望 | ⭐⭐⭐ |
| **健康受损** | 出现明显倦怠、失眠、焦虑等健康问题 | ⭐⭐⭐ |
| **文化冲突** | 价值观严重不合，每天上班很痛苦 | ⭐⭐ |
| **领导问题** | 直属领导无法合作，且内部转岗无望 | ⭐⭐ |
| **行业下行** | 所在行业/公司明显走下坡路 | ⭐⭐⭐ |
| **有绝佳机会** | 拿到了一个很难得的 offer（大厂/高增长/高薪资） | ⭐⭐⭐ |

### 1.2 不该跳的信号

| 信号 | 说明 |
|------|------|
| **才入职不到 1 年** | 太短了，下家会质疑稳定性 |
| **只是因为一时情绪** | 和领导吵了一架/项目不顺就想走 |
| **还没学到核心技能** | 再待 1 年能学到更多，跳出去也没竞争力 |
| **市场行情不好** | 裁员潮中跳槽风险高 |
| **只是为了涨一点薪** | 涨幅 <15% 不值得跳，隐性成本更高 |
| **逃避问题而不是追求机会** | 有些问题换了工作还会遇到 |

### 1.3 黄金跳槽时机

| 时机 | 为什么好 |
|------|---------|
| **入职 2-3 年** | 学到了东西，又不显得不稳定 |
| **拿到年终奖后** | 不亏，年初机会也多 |
| **金三银四/金九银十** | 招聘旺季，岗位多 |
| **完成大项目后** | 简历上多了一个亮点，谈薪更有筹码 |
| **有 offer 在手时** | 骑驴找马，选择更从容 |

## 二、跳槽的成本计算

### 2.1 显性成本

| 成本项 | 说明 |
|--------|------|
| 年终奖损失 | 年中跳槽损失当年年终奖 |
| 公积金/社保断缴 | 断缴影响购房资格、医保 |
| 试用期降薪 | 试用期通常 80% 工资 |
| 搬家/通勤成本 | 换城市或更远的通勤 |
| 找工作期间收入损失 | 裸辞的话没有收入 |

### 2.2 隐性成本

| 成本项 | 说明 |
|--------|------|
| 信任成本 | 新公司需要重新建立信任和影响力 |
| 学习成本 | 新业务、新系统、新同事，3-6 个月适应期 |
| 社交成本 | 离开熟悉的团队，重新建立关系 |
| 机会成本 | 如果留下可能有晋升/加薪 |
| 心理成本 | 适应期的压力和不确定性 |
| 简历成本 | 多跳一次，简历上多一段经历 |

### 2.3 跳槽收益计算

```
跳槽收益 = (新总包 - 旧总包) × 预期工作年限
         - 显性成本（年终奖损失等）
         - 隐性成本的折算值
```

**简单判断：** 如果涨幅不到 20%，且职级没提升，通常不值得跳——隐性成本会吃掉涨幅。

## 三、骑驴找马策略

### 3.1 为什么要骑驴找马

- **经济安全**：有收入，不焦虑
- **谈判筹码**：在职状态谈薪更有底气
- **时间充裕**：可以慢慢挑，不用急着接不满意的 offer
- **风险控制**：面不上也没关系，还有退路

### 3.2 在职找工作的技巧

| 技巧 | 说明 |
|------|------|
| **低调投递** | 不要在公司电脑上投，不要让同事知道 |
| **合理安排面试** | 请事假/年假，或安排在非工作时间（如晚上/周末） |
| **简历设置** | 在招聘平台设置"对当前公司不可见" |
| **背调保护** | 新公司做背调前一定要先通知你，不要让现任公司提前知道 |
| **不要影响当前工作** | 把手头工作做好，不要因为找工作分心出错 |

### 3.3 面试请假理由

- "家里有点事"（万能）
- "去医院做个体检"
- "有个朋友/亲戚过来"
- "房子的事情要处理一下"

**原则：** 简单模糊，不要编造太复杂的故事——圆不了。

## 四、跳槽频率与职业发展

### 4.1 跳槽频率的市场看法

| 频率 | 市场印象 | 建议 |
|------|---------|------|
| 每份 < 1 年 | 不稳定，简历筛选容易被刷 | 尽量避免，除非有合理解释 |
| 1-2 年 | 偏短，需要解释 | 控制在合理范围 |
| 2-3 年 | 正常 | 大多数人的节奏 |
| 3-5 年 | 稳定且有成长 | 很好 |
| 5 年以上 | 非常稳定 | 好，但要注意技能是否更新 |

### 4.2 频繁跳槽的解释话术

如果简历上有几段短经历，面试时一定会被问。怎么回答：

**话术 1（转型探索型）：**
> "刚毕业那两年确实在探索自己适合什么方向，做了两份不同的工作。后来确定了[方向]，就稳定下来了，在[上一家公司]做了 X 年。"

**话术 2（客观原因此）：**
> "上一份工作只做了 1 年，主要是因为[客观原因，如公司业务调整/团队解散]。不是个人原因，这个比较遗憾。"

**话术 3（追求成长型）：**
> "我之前的几份工作跨度比较大，每一次都是为了学习不同的东西。现在我觉得积累得差不多了，想找一个能长期发展的平台。"

## 五、不同年龄段的跳槽策略

### 5.1 工作 1-3 年（探索期）

- 可以多尝试，但不要"乱跳"
- 每跳一次要有明确的成长目标
- 这个阶段探索成本最低，找到方向最重要
- 避免：因为一点不爽就跳，跳了之后发现还不如之前

### 5.2 工作 3-5 年（建立期）

- 跳槽要考虑职级提升
- 从"执行者"向"负责人"过渡
- 关注行业积累，不要频繁跨行
- 目标：在一个方向上建立专业度

### 5.3 工作 5-10 年（发展期）

- 跳槽更看重平台和长期发展
- 考虑管理路线 vs 专业路线
- 薪酬不是唯一因素，资源和影响力更重要
- 稳定性权重上升

## 六、常见跳槽陷阱

| 陷阱 | 说明 | 怎么避免 |
|------|------|---------|
| **只看薪资** | 高薪但做的事没成长，2 年后更难跳 | 看成长>看钱 |
| **头衔通胀** | "总监"满天飞，实际是光杆司令 | 看汇报线、团队规模、职责范围 |
| **画饼** | "以后给你期权""未来有晋升" | 只看写进合同的，不看口头承诺 |
| **同行挖角** | 对手公司挖你，可能只是为了获取信息 | 仔细评估公司和岗位真实性 |
| **逃避式跳槽** | 因为遇到困难就跳，下一家还会遇到同样问题 | 先区分是环境问题还是自身模式问题 |
| **盲目转行** | 听说某个行业赚钱就跳，完全不了解 | 先做信息访谈和小规模实验 |

## 七、跳槽决策清单

- [ ] 在当前公司已经学不到新东西了（连续 6 个月以上）
- [ ] 薪酬低于市场水平 20% 以上，且内部加薪无望
- [ ] 尝试过内部转岗/沟通，没有改善
- [ ] 有明确的下一个方向（不是"先辞了再说"）
- [ ] 存款至少 3 个月生活费（骑驴找马）/ 6 个月（裸辞）
- [ ] 市场行情尚可，我的技能有需求
- [ ] 预计跳槽涨幅 ≥ 20% 或有职级提升
- [ ] 已经做了目标公司和岗位的调研
- [ ] 想清楚了下一份工作 3 年后会比现在好
- [ ] 不是因为一时冲动或情绪

**打勾少于 6 个：** 建议再想想，可能不是好时机
**打勾 6-8 个：** 可以开始看机会，骑驴找马
**打勾 9 个以上：** 果断跳，别犹豫

---

> **停止条件：** 如果你已经在"要不要跳"这个问题上纠结了 3 个月以上还没有结论，说明信息不够——先去做 3-5 个信息访谈，了解一下外面的市场行情，再做判断。纠结本身不会给出答案，信息会。
