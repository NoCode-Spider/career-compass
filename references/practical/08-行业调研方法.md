# 08-行业调研方法

> 适用场景：想了解一个行业/岗位，但不知道从哪入手。
> 目标读者：职业探索者、转行者、求职者。

---

## 一、行业调研的三个层次

| 层次 | 了解什么 | 信息来源 | 深度 |
|------|---------|---------|------|
| 宏观层 | 行业趋势、市场规模、政策环境 | 行业报告、新闻、政策文件 | 浅 |
| 中观层 | 公司格局、竞争态势、岗位结构 | 公司官网、财报、招聘信息 | 中 |
| 微观层 | 真实工作内容、体验、坑 | 从业者访谈、社群、实习 | 深 |

**核心原则：** 不要只看报告和新闻（宏观层），一定要做到微观层——真实从业者的体验才是最有价值的信息。

---

## 二、宏观层：行业趋势调研

### 2.1 信息来源

| 来源类型 | 具体渠道 | 适合了解什么 |
|---------|---------|-------------|
| **行业报告** | 艾瑞咨询、易观分析、QuestMobile、IDC、Gartner | 市场规模、用户数据、趋势判断 |
| **咨询公司报告** | 麦肯锡、贝恩、波士顿咨询、德勤 | 行业格局、战略洞察 |
| **券商研报** | 东方财富、慧博投研资讯 | 行业财务数据、上市公司分析 |
| **官方数据** | 国家统计局、工信部、人社部 | 宏观经济、就业数据 |
| **新闻媒体** | 36 氪、虎嗅、晚点 LatePost、财经 | 行业动态、公司新闻 |
| **上市公司财报** | 交易所官网、巨潮资讯 | 真实业务数据、营收结构 |

### 2.2 调研框架

看一个行业时，搞清楚这几个问题：

| 问题 | 为什么重要 |
|------|-----------|
| 这个行业是做什么的？ | 基本认知 |
| 市场规模多大？增速如何？ | 判断是朝阳还是夕阳 |
| 主要玩家有哪些？格局如何？ | 头部集中还是分散 |
| 核心商业模式是什么？ | 怎么赚钱的 |
| 行业处于什么阶段？ | 萌芽/成长/成熟/衰退 |
| 有什么政策影响？ | 监管风险还是政策红利 |
| 技术趋势是什么？ | AI/新技术会不会颠覆 |
| 人才需求怎么样？ | 缺不缺人，薪资水平如何 |

### 2.3 快速调研法（2 小时版）

如果你只有 2 小时，按这个顺序：

1. **30 分钟**：找 1-2 份最新行业报告，看核心结论（不看细节）
2. **30 分钟**：找 3 篇行业深度文章（晚点/36氪深度）
3. **30 分钟**：看 2-3 家头部公司的官网和最新财报/融资新闻
4. **30 分钟**：在招聘平台搜相关岗位，看薪资范围和要求

## 三、中观层：公司与岗位调研

### 3.1 公司调研

| 维度 | 信息来源 | 看什么 |
|------|---------|--------|
| 基本信息 | 官网、百科、企查查 | 成立时间、规模、融资阶段 |
| 产品/业务 | 产品体验、App Store 评论 | 主打产品、用户评价 |
| 财务状况 | 财报、融资新闻 | 赚不赚钱、烧钱速度 |
| 团队/创始人 | 新闻、LinkedIn | 背景、过往经历 |
| 员工评价 | 脉脉、看准网、玻璃门 | 工作氛围、薪资、加班情况 |
| 负面新闻 | 搜索引擎、黑猫投诉 | 有没有雷 |

### 3.2 岗位调研

从 JD 中提取信息，但 JD 不等于真实工作——要区分"写的"和"实际的"。

| JD 上写的 | 实际可能是 |
|-----------|-----------|
| "有激情" "能抗压" | 经常加班 |
| "扁平化管理" | 没什么层级，也没什么晋升空间 |
| "有期权" | 大概率拿不到，画饼 |
| "弹性工作制" | 加班不给加班费，什么时候做完什么时候走 |
| "能独立负责项目" | 人手少，什么都得干 |

**怎么了解真实岗位情况？** — 找从业者聊（见下一节）。

---

## 四、微观层：信息访谈

### 4.1 信息访谈是什么

找正在目标行业/岗位工作的人做 20-30 分钟的交流，获取一手信息。**这是行业调研最有价值的一步。**

### 4.2 怎么找人

| 渠道 | 方法 | 成功率 |
|------|------|--------|
| **熟人介绍** | 朋友/同学/前同事介绍 | 最高 |
| **LinkedIn/脉脉** | 直接发消息 | 中（10-20% 回复率） |
| **行业社群** | 微信群/知识星球/论坛 | 中 |
| **线下活动** | 行业沙龙、meetup | 高（面对面更容易建立联系） |
| **内容平台** | 知乎/掘金/小红书上找到从业者，私信 | 低 |

### 4.3 邀约话术

**脉脉/LinkedIn 私信模板：**
> 您好，我是[你的名字]，目前在做[当前工作]，对[目标方向]很感兴趣，正在了解中。看到您在[公司/领域]的经验，想请教几个问题，不会耽误您太多时间，20 分钟就好。不知道您方便吗？可以请您喝杯咖啡/发个红包表示感谢。

**要点：**
- 自我介绍要简短
- 说明来意（请教，不是找工作）
- 表示尊重对方时间
- 主动提供回报（咖啡/红包/知识交换）
- 不要一上来就要内推

### 4.4 问什么

**必问的 10 个问题：**

1. "您能简单介绍一下您的日常工作吗？" — 真实工作内容
2. "您觉得这份工作最有成就感的部分是什么？" — 好的一面
3. "最让您头疼/想吐槽的部分是什么？" — 不好的一面（关键！）
4. "入行 1-3 年的人大概是什么状态？" — 你可能的状态
5. "这个岗位的核心能力要求是什么？" — 你需要补什么
6. "这个行业未来 3-5 年您怎么看？" — 趋势判断
7. "什么样的人适合做这个？什么样的人不适合？" — 匹配度判断
8. "薪资大概是什么水平？" — 委婉但要问
9. "如果想入行，您有什么建议？" — 行动建议
10. "有没有其他我应该了解但没问到的？" — 开放式，常有惊喜

### 4.5 注意事项

- **提前做功课**：不要问百度就能查到的问题
- **控制时间**：说好 20 分钟就 20 分钟，对方愿意聊可以延长但不要主动拖
- **不要推销自己**：信息访谈是请教不是找工作（除非对方主动问）
- **表示感谢**：发个红包或请喝咖啡是基本礼仪
- **保持联系**：加个微信，后续有进展可以反馈一下（"谢谢您的建议，我后来做了 XX"）

## 五、避免信息偏差

### 5.1 常见偏差

| 偏差 | 表现 | 怎么避免 |
|------|------|---------|
| **幸存者偏差** | 只看到成功的人，没看到失败的 | 主动问"什么样的人做不好" |
| **光环效应** | 因为喜欢某个产品就觉得整个行业都好 | 区分产品体验和工作体验 |
| **从众心理** | "大家都去我也去" | 别人适合的你不一定适合 |
| **短期波动** | 把短期热点当长期趋势 | 看 3-5 年趋势，不看 1 年 |
| **单一信息源** | 只看了一个人的说法 | 至少找 3-5 个人聊，交叉验证 |

### 5.2 验证信息的方法

- **三角验证**：同一个问题，问 3 个不同的人，看答案是否一致
- **正反都听**：既找喜欢这个行业的人聊，也找离开的人聊（"你为什么离开"）
- **亲身验证**：最好的验证是做一个小项目/实习/兼职，亲身体验

## 六、行业调研清单

- [ ] 读了 2-3 份行业报告
- [ ] 看了 3-5 篇深度文章
- [ ] 了解了行业头部公司和格局
- [ ] 看了目标岗位的 10+ 条 JD
- [ ] 做了至少 3 个信息访谈
- [ ] 了解了好的一面和不好的一面
- [ ] 知道了入行门槛和核心能力要求
- [ ] 对薪资水平有了概念
- [ ] 交叉验证了关键信息（不是只听一个人说）
- [ ] 有了自己的判断，而不是人云亦云

---

> **停止条件：** 如果你做了 5+ 信息访谈、读了 5+ 篇深度报告、看了 20+ 条 JD，还是不确定要不要进入这个行业，可能不是信息不够，而是你内心有顾虑——回到知识库 01 和 02，做职业锚和决策困难分析。有时候信息收集到一定程度就够了，再收集也不会改变决策。
