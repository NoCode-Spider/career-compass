# 04-离职决策与流程

> 适用场景：正在考虑要不要离职，或者已经决定要离职。
> 目标读者：考虑离职或准备离职的职场人。

---

## 一、离职决策判断

### 1.1 该走还是该留？

**离职信号判断表：**

| 维度 | 该走的信号 | 该留的信号 |
|------|-----------|-----------|
| **成长** | 学不到新东西，技能停滞 1 年以上 | 还有成长空间，有导师/新机会 |
| **满意** | 三需要长期被剥夺（自主/胜任/关联） | 至少 2 个需要满足 |
| **环境** | 领导/文化问题无法改变 | 团队氛围好，只是某个问题 |
| **经济** | 薪酬远低于市场，加薪无望 | 薪酬合理或有明确加薪路径 |
| **健康** | 出现倦怠/失眠/焦虑等健康问题 | 不影响身心健康 |
| **市场** | 外部机会多，你的技能有需求 | 市场不好，你的经验难找下家 |

### 1.2 辞职前的七问

在提交辞职信之前，诚实回答这七个问题：

1. **我是因为什么想走？** — 是具体问题（某个领导/项目）还是系统性问题（行业/公司/自身）？
2. **这个问题能通过内部转岗或沟通解决吗？** — 很多人离职是因为"不敢提需求"而非"真的不能解决"
3. **下一份工作能解决这个问题吗？** — 别把"换工作"当万能药，有些问题换了环境还会重复
4. **我有足够的积蓄吗？** — 至少 6 个月生活费（裸辞的话）
5. **现在是好的时机吗？** — 年底有年终奖吗？市场行情怎么样？
6. **我走了以后，下一家会更好吗？** — 有没有具体的目标公司和方向？
7. **如果不走，1 年后我会后悔吗？** — 反过来想，留下 1 年会不会更后悔？

### 1.3 绝对不要裸辞的情况

- [ ] 存款少于 3 个月生活费
- [ ] 没有明确的下一个方向
- [ ] 仅仅因为一时冲动（和领导吵了一架）
- [ ] 市场行情不好（裁员潮/经济下行）
- [ ] 你的技能在市场上稀缺性低
- [ ] 有房贷/车贷/家庭等固定大额支出

## 二、离职流程

### 2.1 时间线

| 时间点 | 动作 | 注意事项 |
|--------|------|---------|
| T+0 | 决定离职 | 不要告诉任何同事 |
| T+1 | 先和直属领导谈（口头） | 面对面或视频，不要文字说 |
| T+3 | 提交正式书面申请 | 邮件+系统，保留证据 |
| T+3 ~ T+30 | 工作交接 | 认真交接，好聚好散 |
| T+30 | 最后工作日 | 办离职手续，拿离职证明 |

**法律规定：** 正式员工提前 30 天通知，试用期提前 3 天通知。

### 2.2 和领导谈离职的话术

**话术 1（简洁专业型）：**
> "老板，我想和您说一下，我经过慎重考虑，决定离职。主要是想在[方向]上有更多发展，也找到了更适合的机会。接下来一个月我会认真做好交接，确保项目顺利过渡。"

**话术 2（感恩型）：**
> "老板，谢谢您这段时间的照顾。我在公司学到了很多。但经过考虑，我决定去尝试一个新的方向。离职申请我稍后会发邮件。交接方面您放心，我一定安排好。"

**注意：**
- 不要抱怨、不要批评、不要说公司坏话
- 不要说具体下家是哪家（除非你想说）
- 不要被"加薪挽留"动摇——如果钱是唯一问题，当初为什么不提加薪？
- 态度坚定但礼貌，不要反复

### 2.3 离职原因怎么说

| 离职原因 | 能不能说 | 推荐说法 |
|---------|---------|---------|
| 钱太少 | ❌ 不要直接说 | "想寻求更好的发展机会" |
| 领导不好 | ❌ 绝对不要说 | "想换一个环境挑战自己" |
| 太累了 | ⚠️ 可以委婉说 | "想调整一下状态，找一个节奏更适合的工作" |
| 学不到东西 | ⚠️ 可以但要委婉 | "想在[某方向]上深入发展，目前的岗位空间有限" |
| 找到了更好的机会 | ✅ 可以 | "拿到了一个更符合我长期发展的 offer" |
| 想转行 | ✅ 可以 | "想往[新方向]发展，做一些职业方向上的调整" |

**核心原则：** 说好聚好散，不说负面评价。世界很小，山水有相逢。

## 三、工作交接

### 3.1 交接清单

| 类别 | 交接内容 |
|------|---------|
| **项目** | 所有负责项目的进度、文档、待办事项 |
| **文档** | 账号、密码、权限、共享文件位置 |
| **关系** | 对接的同事、客户、合作方联系方式 |
| **代码/资产** | 代码仓库、设计稿、数据文件 |
| **流程** | 日常工作流程、注意事项、常见问题 |
| **工具** | 使用的工具、订阅、账号归属 |

### 3.2 交接文档模板

   - 对接人：XXX

   ...

- 其他：

### 四、联系方式
- 产品对接：XXX
- 技术对接：XXX
- 客户对接：XXX

### 五、注意事项

### 3.3 交接期注意事项

- **认真交接**：这是职业素养的体现，也是给自己留后路
- **不要摸鱼**：交接期也是你在公司口碑的最后一笔
- **不要吐槽**：交接期不要和同事说公司坏话
- **不要带走公司资产**：代码、数据、客户信息等绝对不能带走
- **保持联系**：和关系好的同事/领导保持联系，人脉是长期资产

## 四、社保与公积金衔接

### 4.1 社保断缴的影响

| 保险 | 断缴影响 | 能否补缴 |
|------|---------|---------|
| 养老保险 | 累计计算，断缴影响不大（影响退休金总额） | 可以 |
| 医疗保险 | 断缴期间不能报销，断缴 3 个月以上连续缴费年限清零（部分城市） | 3 个月内可补 |
| 失业保险 | 累计计算 | — |
| 生育保险 | 断缴后不能享受生育津贴 | 需连续缴满一定期限 |
| 公积金 | 断缴影响公积金贷款申请 | 可以补缴 |

### 4.2 裸辞期间社保怎么办

| 方式 | 说明 | 适合谁 |
|------|------|--------|
| 灵活就业缴纳 | 自己交养老+医疗 | 本地户口 |
| 找代缴公司 | 第三方代缴全部五险一金 | 非本地户口 |
| 居民社保 | 交居民养老+居民医疗 | 预算有限 |

**提醒：** 代缴公司存在合规风险，选择正规机构。

### 4.3 公积金处理

| 选项 | 说明 |
|------|------|
| 转移 | 新公司继续缴纳，自动累计 |
| 提取 | 租房、买房、装修等条件下可提取 |
| 封存 | 暂时不动，等以后再说 |

## 五、竞业限制

### 5.1 签了竞业协议怎么办

1. **离职时确认公司是否启动**：不是签了就生效，要看公司是否按月支付补偿
2. **补偿标准**：不低于离职前 12 个月平均工资的 30%（部分地区更高）
3. **如果公司不支付补偿**：超过 3 个月不支付，可以请求解除竞业限制
4. **如果违反**：需要支付违约金，且可能被要求继续履行

### 5.2 风险提示

- 竞业限制不是"吓唬人的"——大厂真的会告
- 不要心存侥幸"公司不会发现"
- 如果不确定下家是否在竞业范围内，咨询劳动法律师
- **本 skill 不提供法律建议，具体情况请咨询专业律师**

## 六、离职后事项清单

- [ ] 拿到离职证明（必须，下家入职需要）
- [ ] 社保公积金确认已停缴
- [ ] 公司电脑/工牌/钥匙归还
- [ ] 个人物品带走，公司资料删除
- [ ] 退出公司所有群聊
- [ ] 更新简历和 LinkedIn
- [ ] 和关系好的同事告别，保持联系
- [ ] 休息几天，调整状态再出发

## 七、常见误区

| 误区 | 正确做法 |
|------|---------|
| "离职要轰轰烈烈" | 好聚好散，世界很小 |
| "交接期可以摸鱼了" | 交接质量体现职业素养 |
| "和领导撕破脸" | 没必要，山不转水转 |
| "裸辞很潇洒" | 潇洒一时，焦虑很久 |
| "下家一定更好" | 不一定，每家公司都有自己的问题 |
| "同事都舍不得我走" | 别太高估自己的不可替代性 |
| "离职前要把不满都说出来" | 说了也不会改变什么，反而可能影响背调 |

---

> **停止条件：** 如果你已经想离职超过 6 个月、尝试过内部解决但没用、且有至少 6 个月积蓄，那大概率该走了。如果你只是最近一两周心情不好，先别急——可能是短期情绪波动，不是真的需要离职。
